Access

Customer > Electronic Interfaces > Checks > View Customer Signatures

Use this routine to view, but not edit, an archive of check transactions. You cannot edit archived data. To access this routine, you must have the Signature Capture feature installed on your PC and the feature must be active in

the General System Control Settings,

the Signature Capture Settings, and

your log-on location.

NOTE: Because this program is used to view but not edit previously captured signatures, you do not have to connect a signature tablet to your PC to run this routine.

Checking Account Number Checking Account NumberEnter the number of the checking account whose transactions you want to view. After you enter the number, the system encrypts it so that only the last four digits are legible in the field. If you enter only four numbers into this field, the system displays all transactions for credit cards whose last four numbers match the numbers you enter here.

Grid InformationGrid Information

All transactions associated with the selected checking account (including transactions from other locations in your organization, if any) appear in the grid. The grid displays the following information for each item in the grid:

Store code - The store where the transaction was entered (this store may be different than the store currently viewing the archive)

Customer code and customer name - The STORIS customer code and name appear.

Transaction number - The order number may be a regular sales order, a customer return, an exchange, or an open item receivables reference number.

Order type - The order type is either sales or credit.

Date - The date on which the payment was processed and signature attempted appears.

If you double-click on a grid item, the Electronic Check Inquiry screen appears where you can access detailed information about the selected transaction.

Electronic Signatures

If an electronic signature was recorded at the time of a transaction, the signature displays on the Electronic Check Inquiry screen when you double-click on the transaction in the grid. Otherwise, a description of the action taken at the time appears in the signature space (for example, Skipped, Cancelled, or Signature Not Available).

Printing

This routine generates graphical print files similar to PrintScreen images. In this way, you can print stored electronic signatures. When you click on Print in this routine, instead of bringing you to the familiar STORIS print function, the system brings you to the Windows® Print Window where you can choose your print destination from a list of printers installed on your local PC. To print to the default STORIS printer, you must install it on your PC.
