AccessAccess

Via all screens that require you enter a root GL account, for example the View Account Activity Inquiry.

Use this screen to search for existing root GL accounts based on a word or substring from either the GL account key or the account description.

Enter a word string into the either the Account field, the Description field, or both, and press Enter. If you enter both, the Description field acts as a filter to the Account field. All GL accounts containing the word string appear in the grid.
