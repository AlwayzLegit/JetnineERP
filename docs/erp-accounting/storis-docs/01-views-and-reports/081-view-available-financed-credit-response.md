This screen appears when you click on Run in the View Available Financed Credit routine. It displays available credit information for the selected customer and account number.

Customer Number Customer Number

The customer code displays in this read-only field.

Social Security Number Social Security Number

The social security number is masked but shows the last 4 digits. This field is read-only.

Account Number Account Number

This read-only field is always displayed for Alliance Data Services. For all other providers, it is visible only if you have permission via the View encrypted finance, credit card, check account numbers setting in Create a User/Group Actions - Sales Security.

Finance Comment Finance Comment
