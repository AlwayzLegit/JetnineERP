Access

Customer > Coordination and Logistics > Credit Application > View Completed Credit Requests

Customer > Electronic Interfaces > Credit Application > View Completed Credit Requests

Accounting > Receivables > Credit Application > View Completed Credit Requests

Use this routine to display a list of approved or declined credit requests for a selected customer. Once you specify a customer code, the grid displays the results in descending order by credit request completion date/time. The grid includes the following information:

Request Date

Request Time

Completion Date

Completion Time

Reviewer

Status

Order Number

Letter Printed

Credit Request ID

If you double-click on a grid line, the Credit Request Review Screen - Read Only appears from which you can view detailed information on the selected line item and/or print status letters.

Customer CustomerEnter the customer whose completed credit requests you want to view. If you click on the Search button, the Search for a Customer screen appears.

Grid InformationGrid Information

The grid displays the selected credit requests and the following information for each:

Customer Name

Number - customer code

Status - credit request status

Date - credit request status change date

Time - credit request status change time

Bureau - credit bureau code

Store - selling store

Salesperson - salesperson ID

Reviewer - credit request reviewer's ID

If you double-click on a grid line, the Credit Request Review Screen - Read Only appears from which you can view detailed information on the selected line item and/or print status letters.
