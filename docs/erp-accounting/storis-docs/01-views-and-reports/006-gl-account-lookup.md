AccessAccess

Post a Journal Entry/Details Tab/Action button at Account field

Use this screen to lookup complete GL account numbers based on any combination of the following:

account classification

account element

account description

If you click on the Search button without entering any search criteria, the lookup returns all account numbers (this may take a minute or two) and displays them in the grid. To restrict your search, use one or more of the fields below. To select an item, double-click on it in the grid. The system returns you to the main screen.

Account Group Account GroupUse this field to restrict your lookup to a selected account group. If you click on the Arrow, a list of valid account groups appears, from which you can make a selection. If the selected account group includes an associated account sub-class and/or class, each displays at its respective field below and you cannot edit those fields.

Account Subclass Account SubclassUse this field to restrict your lookup to a selected account sub-class. If the selected subclass includes an associated account class, that class displays at the Class field below and you cannot edit it.

Account Class Account ClassUse this field to restrict your lookup to a selected account class.

Account AccountUse this field to restrict your lookup to a selected root account. If you click on the Arrow, a list of valid accounts appears from which you can make a selection. If you click on the Search button, you access the Multiple GL Account Selection Screen. If you click on the Action button, you access the GL Account Description Lookup.

Sub-Account Sub-Account

Use this field to restrict your lookup to one or more selected sub-accounts. This field is active only if you are using sub-accounts.

If you click on the Arrow, a list of available sub-accounts appears. The list is affected by security restriction (if any) in the User file. If you click on the Search button, you access the Multiple GL Sub-Account Selection Screen, from which can select one, multiple, or a range of sub-accounts.

Description DescriptionEnter a full or partial account description. The lookup searches all root accounts and returns those whose description contains the string you enter here.

Search SearchClick on this button to execute your search based on the specified criteria. Note that this button is always be active so you can modify your search criteria and refine your search.
