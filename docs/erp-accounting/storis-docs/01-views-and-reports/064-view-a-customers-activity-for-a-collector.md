Access

Accounting > Collections > View a Customer's Activity for a Collector

This routine is a STORIS standard DTS inquiry. You can modify its contents (via the Dynamic Tab Settings (DTS Setup) routine), but you cannot delete it. Because DTSs are user-defined and changeable, the descriptions in this Help topic may not match the DTS you see on your screen. This topic describes the DTS as it appears when you first install STORIS.

After you specify a customer to view, information on the customer appears on the screen. Click on the other tabs to view additional information.

NOTE: The output of this inquiry may be affected by Regional Processing restrictions. That is, you can inquire only about customers and locations to which you have access.

The following tabs are standard to this DTS inquiry.

General Info - View Customer Summary Information

Deposits - View a Customer's Current Deposits (Deposit Inquiry)

Deposits History - View a Customer's Historical Deposits (Deposit History Inquiry)

Customer History - View a Customer's Historical Purchases (Customer Purchase History Inquiry)

Open Items - View a Customer's Current Balance Details (Open Item Receivables Inquiry)

Accounts Receivable - View a Customer's Current Balance Details

A/R History - View a Customer's Historical Balance Details

Open Orders - View a Customer's Open Transactions

Purchases - View Customer's Current Purchases (Customer Order Profile Inquiry)

Service - View a Customer's Open Service Orders (Open Service Order by Customer Inquiry)

Customer Code Customer Code

Enter the code of the customer you want to view. If you click on the Search button, you access the Customer Code Look-Up screen, from which you can select a customer code.

NOTE: The customers you can access at this and other Customer fields may be restricted by Regional Processing.
