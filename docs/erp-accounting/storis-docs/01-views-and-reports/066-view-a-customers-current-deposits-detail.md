Access

Double-click on a grid item in the View a Customer's Current Deposits routine.

Use this screen to view detailed information on deposits selected from the grid from the View a Customer's Current Deposits routine. The Order Number, Order Date, Order Amount, and Deposit Amount are defaulted into the header and cannot be edited.

The grid displays the following information:

Type - The payment type (CASH, CHK, VISA, etc.)

Reference - This information is masked except for the last 4 digits. To view the entire credit card number or check details, click select Credit Card Number Full Display from the Actions button.

Expiration Date

Authorization

Driver's License - This information is masked except for the last 4 digits.

Deposit Date

Amount

ActionsActions

View Masked Finance Data - To view the full credit card number or full check details for ECA checks, click on this option. The Access Control Window prompts you for Initials and Password. You must enter the ID and password of a user who has permission to view this data via the View encrypted finance, credit card, check account numbers in your Create a User/Group Actions - Sales Security settings. Once you gain access, the full credit card number/check details displays in the Reference field.
