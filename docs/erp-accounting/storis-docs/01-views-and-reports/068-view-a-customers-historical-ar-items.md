Access

View Customer Activity > Historical A/R Items

Use this routine to view historical accounts receivable activity, including open item, installment and revolving activity. The header portion of the screen displays read-only information for the selected customer.

This process displays A/R items for the selected period. To see all A/R activity for a customer, use the View a Customer's Receivables Activity Summary process where you can specify a date range via the View a Customer's Receivables Activity Details.

Period Period

Select the fiscal period for which to view the customer's accounts receivables.

Fiscal Year, Date Range Fiscal Year, Date Range

These read-only fields populate based on the selection made in the Period field.
