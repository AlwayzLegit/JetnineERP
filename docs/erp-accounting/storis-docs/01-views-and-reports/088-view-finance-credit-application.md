Access

Accounting > Financing > Financing Views and Reports > Financing Views > View Finance Credit Application

Accounting > Financing > Electronic Transmittal > View a Credit Application

Use this inquiry to view the credit application screens for active credit applications, by selected customer. You cannot edit the information shown in this inquiry using this process.

NOTE: The output of this inquiry may be affected by Regional Processing restrictions. That is, you can inquire only about customers and locations to which you have access.

The fields displayed in this inquiry are identical to those found on the Finance Application entry and Credit Application Maintenance screens. However, the fields in this inquiry may NOT be updated using this process.

Selling Store Selling StoreEnter the code of the selling store at which the credit application was created. The default location from the log-in screen appears, if any. You can override the default response.

If you click on the Arrow, you can choose from the drop-down list of locations available to you. Note that here and at any other Location field , the locations you see (that is, the list of locations available to you) may be affected by Regional Processing restrictions.

Customer Code Customer CodeEnter the code of the customer for whom the credit application was created. If you click on the Search button, you access the Search for a Customer (Customer Code Lookup) window, from which you can search for existing customers. If you click on the Action button, you also access the Customer Code Lookup window. However, when you access from the Action button, you can then access the Customer Settings (Customer Master) routine by clicking on the Exit button. You can use the Customer Settings routine to enter a new customer.

NOTE: The customers you can access at this and other Customer fields may be restricted by Regional Processing.

Finance Provider Finance ProviderThis field is used to indicate the provider of financing for this application. Once the Customer Code has been entered, this field will default to the Finance Provider Settings for the active application and an information window will display the Credit Application Status (application status, date of application, and finance provider).

ActionsActions

When the run-time options have been selected, click the Actions button at the bottom of the screen and select Credit Application Maintenance. The Main tab of the Credit Application screen will display customer information filled in during application entry. If this is a Joint application, the Joint tab is available for review of the customer information for the joint applicant. The specific fields found on these two tabs will vary according to the requirements of the finance provider. When finished reviewing this application, click the Exit button at the bottom of the screen to return to the initial screen.
