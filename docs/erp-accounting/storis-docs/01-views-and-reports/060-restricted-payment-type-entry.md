Access

Indicate Message to Print on Customer Statements, Action button at Plan field

Use this routine to select multiple revolving payment plans. The list of plans you create here is used to select the plans to which you are linking specific statement messages via Indicate Message to Print on Customer Statements.

Pay Type Pay TypeTo indicate the revolving plan type, click the arrow button and select the plan code from the list. Once selected, the plan is automatically added to the grid and another code can be selected.

Description DescriptionThe description for the revolving plan type you selected is displayed.

Grid InformationGrid Information

The grid displays the Pay Type and Description for each revolving plan you selected. To remove a plan from the grid, double-click to select it and then click the Remove button.
