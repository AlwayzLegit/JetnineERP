Access

Use this routine to view revolving disputes sorted by customer and plan. Included in this view are currently disputed transactions, as well as disputes that have been resolved. Disputed transactions can be viewed for all customers or for a selected customer. If you specify a customer, you also have the option of viewing all disputed transactions or selected transactions. Additional selections for this inquiry include reason code and auto-removal date range.

CustomerEnter the code of the customer whose revolving dispute activity you want to view, or you can leave the field blank to view all customers. You can click the Search button to access the Search for a Customer routine. If you specify a customer, the name displays to the right of the field and the Transaction field becomes active.

TransactionIf you are viewing activity for all customers, All Transactions is selected at this field and you cannot change it. If you specify a customer, you can use this field to select a specific dispute transaction to view. Click the Arrow button to select a transaction reference to view.

ReasonYou can indicate a reason code to limit the grid display to only transactions with that reason designated. To locate a valid reason code, click the Search button and access the Read-Only Lookup Window. The reason you specify here must be set to Revolving Disputes in the Reason Usage Code field of your Reason Code Settings. If you leave this field blank, you can view all dispute transactions, regardless of reason code.

Remove on Start, Remove on End If you specified a date for automatic removal of the dispute via the Update Disputes screen, you can specify a date range in these fields to narrow your search for transactions. Only dispute transactions that are/were scheduled for removal from dispute during the date range you specify display in the grid.

Search

Once you have made your selections above, click the Search button to populate the grid based on your choices. If you change an option, such as selecting another customer, you must click the Search button to re-populate the grid based on your new selections.

Grid InformationGrid Information

The grid displays transactions based on your selections above. To view transactions based on different criteria, enter your new selections and then click the Search button to re-populate the grid. The grid displays the following information for transactions listed.

Customer

Plan

Amount

Reason

Posted (date)

Remove On (date dispute scheduled to be removed/resolved during EOD; entered in Remove On field via Update Disputes)

Resolved (date dispute was resolved)

Transaction (reference)

To access the View a Customer's Revolving Disputes routine, double-click a line item in the grid.
