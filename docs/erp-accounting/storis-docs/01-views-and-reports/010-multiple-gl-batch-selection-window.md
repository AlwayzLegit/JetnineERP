Action button at the Batch field in various GL routines, for example the Report Posted Transactions routine.

Use this screen to select one or more General Ledger batches.

Batch BatchEnter the code of a GL batch. If you click on the Search button, you access the View Multiple Postings, which you can use to view and select GL batches.
