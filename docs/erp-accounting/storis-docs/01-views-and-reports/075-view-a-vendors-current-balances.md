Access

Accounting > Vendor Receivables > Vendor Receivables Views > View a Vendor's Current Balances

The Vendor Receivables Open Item Inquiry will display summary and detail information on any open vendor receivable transaction. Summary lines are displayed initially with the original transaction amount and the current amount due for each line item. To view the detail (sub-line items) within a particular transaction, select the line item from the grid.

Vendor VendorEnter the code of a vendor or click the Search button and select a vendor code from the list. Once a vendor has been indicated in this field , open vendor receivable summary transactions for this vendor will display in the grid.

Open Balance Open BalanceThe net open balance of all receivable items for this vendor, less any disputed amount, will display.

Disputed Amount Disputed AmountThe net balance of all receivable items for this vendor that are currently in dispute will display.

Double-click a line item in the grid to view detail for that transaction, including any adjustments, payments, and on account payments/applications.

Detail Comments Detail CommentsOnce a line item is selected to view detail, the detail comments will display. These comments were generated/entered via the Apply Payments and Maintain Vendor Receivables Balances entry process.
