AccessAccess

Use this routine to report:

receivables collected today, yesterday, month-to-date, and year-to-date for each collector,

their quotas, and

the difference between the amount collected and the quota.

Amounts display in whole dollars. Once the report criteria have been selected, click Run to produce the report.

NOTE: You can also run this report as part of the End-of-Month process.

Report Period Report Period

Specify the report period on which to report. You have the following options:

Current

Prior

This field is active only when in an overlap condition. When this report runs as part of End-of-Month processing, the program uses the current period.

Collector CollectorEnter the code of the collector (if any) on whom to report. If you click on the Search button, a list of collectors appears from which you can choose one or more. When this report runs as part of via End-of-Month processing, the program processes all collectors.

Send Output to Send Output toThe output destination of the report displays. To change the output destination, click on the Actions button and select Output Settings.

Export Path Export PathIf you select either the Personal Report Viewer (PRV), Excel Export, or ASCII Export, this field displays the pre-set computer drive and folder location to which the system exports the report data. You cannot edit the export path using this process.
