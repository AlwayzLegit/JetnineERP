Access

Accounting > General Ledger > Account Budgets > View an Existing Account Budget

Use this routine to view budget amounts for a specified account for a specified fiscal year. Along with the budget amounts for each fiscal period, the actual activity, variance amount, and variance percentage display in the grid.

Company CompanyEnter the company for which you want to run this inquiry. If multi-company processing is active, click on the Arrow to display a list of available companies. Otherwise, the default company appears and you cannot edit this field.

Fiscal Year Fiscal YearEnter the fiscal year for which you want to run this inquiry. If multi-company processing is active, click on the Arrow to display a list of available fiscal years.

Account AccountEnter the account whose budget you want to view. If you click on the Action button, the GL Account Entry Screen appears which you can use to select an account.

Grid InformationGrid Information

Budget information appears for the selected account, including the following information:

Period Ending

Activity This Year

Budget This Year

Variance $

Variance %

NOTE: In the Activity This Year column, if no activity occurred for a period in the grid, the grid displays that period's activity from the previous year and denotes with an asterisk (*).
