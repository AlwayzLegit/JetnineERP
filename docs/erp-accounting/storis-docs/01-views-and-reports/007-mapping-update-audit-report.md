Use this process to report on orders that were not added to the manifest. This process only appears when any third party mapping interface, such as RouteView or Advanced Dispatch Track, is active on you system. When using third party mapping programs, the routing is done there and then transferred back to STORIS to have a manifest build of the orders; there may be instances where the order failed to be added to the manifest.

Select the Location for which you wish you run the report. Only one location can be selected. The report results can be refined by selecting a Scheduled Date (i.e. delivery date) and/or a Download Date.

Use the Report field to report on mapping updates for either all updates (i.e. select All) or updates since the report was last run (i.e. select New).
