Access

Accounting > Payables > Process Checks > View Check Status and Payment Details

Accounting > Payables > Payables Views and Reports > View Check Status and Payment Details

via the EFT Batch Number field in the Create Electronic Funds Transfer File routine.

Use this inquiry to display information on checks and payments for a specified bank, check run date, and time. This is a read-only version of the Select and Approve Bills for Payment routine. The fields are identical in both screens, but you can only specify the check run to view in this read-only version.

Header Area

Use this area to specify the check run record you want to view.

Bank BankEnter the bank for which you want to view a check run. If you click on the Arrow, a list of valid banks appears from which you can choose. Once you select a bank for which one or more check runs exist, the Date field activates.

Date DateOnce you select a bank for which one or more check runs exist, this field activates. If only one check run exists for the bank, the date of that check run appears and information for that check run appears on the screen.

If multiple check runs exist, click on the Arrow to select the date on which the check run you want to view occurred. If multiple check runs exist for the date you select, the Time field activates and you must select a specific check run from the Time field.

Time/Code Time/Code

For check runs using the same bank and check date, unique times of day allow you to distinguish the check runs.

For single batch: This field label is 'Time'. If only one check run exists for the selected date, the time of the check run appears and this field inactivates. If more than one check run exists for the date, click on the Arrow to display all check runs for the selected date and then select from the list that appears.

For multiple batches: This field label is 'Code'. Use this free-text field to enter the batch code, up to 10 characters.

Type Type

The transaction type displays. Possible types are:

Printed Checks

Electronic Funds Transfer

Status Status

The status of the check run appears. Possible statues are:

Pending - not yet printed

Printed – check run has been printed

Once the information for the header area is complete, the tabs activate. Note that for new check runs, only the Bill Selection tab activates.

NOTE: The entry version of the remaining fields on this screen are documented in the Select and Approve Bills for Payment topic.
