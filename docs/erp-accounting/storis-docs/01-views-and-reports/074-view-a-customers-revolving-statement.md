Access

Accounting > Revolving Receivables > Revolving Views and Reports > Revolving Views > View a Customer's Revolving Statement

Page Headings: Revolving Statement, General

Use this routine to view Revolving Receivables statement history for a specified customer. Access to several other inquiry screens is also available from this routine. You can use the Dynamic Tab Settings routine to add screens/tabs and create a user-defined DTS (dynamic tab select) inquiry.

NOTE: This routine is a STORIS standard DTS inquiry. You can modify its contents via the Dynamic Tab Settings (DTS Setup) routine, but you cannot delete it. Since DTSs are user-defined and changeable, the descriptions in this topic may not match the DTS you see on your screen. This topic describes the DTS as it appears when you first install STORIS.

The output of this inquiry may be affected by Regional Processing restrictions. That is, you can inquire only about customers and locations to which you have access.

CustomerCustomer

Enter the code of the customer to view transactions for that customer. Click the Search button to access the Search for a Customer routine.

This field may be populated automatically and inactive if this screen is accessed from View All Revolving Plan Activity for a Customer.

Once the customer is selected, the Cell Phone, Home Phone, Work Phone, Ext, and Email Address fields populate. These fields are read-only.

Revolving Statement

Use this page to view revolving statement details for the specified plan and statement period.

PlanPlanSpecify the code of the revolving plan to view. Click the Arrow button to select a code from the list of active plans for this customer.

Statement Month/YearStatement Month/YearWhen you first access this page, this field defaults based on the last cycle date for the plan. Click the Arrow button and select another statement period to view.

Cycle

Start Date, End DateStart Date, End DateThe cycle start and end dates for the specified statement and plan display.

Average Daily BalanceAverage Daily BalanceThe average daily balance for the selected plan and statement period is displayed.

Current DueCurrent DueThe amount due for the specified statement and plan display.

Statment MessagesStatment Messages

Click this button to view automatic and manually assigned revolving statement messages that appeared on the selected customer statement. The View a Customer's Statement Messages screen appears.

Payment AgreementPayment Agreement

This extra action button is active only when an active plan with a payment agreement exists for this customer. Click the button to view the Enter Payment Agreement window in query mode.
