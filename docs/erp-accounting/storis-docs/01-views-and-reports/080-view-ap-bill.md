Access

Accounting > Payables > View AP Bill

Accounting > Payables > Payables Views and Reports > View AP Bill

Tabs: General, Invoice Detail, Check Information

Use this routine to view both open and closed AP bills. This is a read-only routine. That is, once you specify a bill to view, you cannot edit any other fields in this routine. To edit or create AP bills, use the Enter/Update Individual Expense Invoice routine.

NOTE: If you reached this routine via the Enter Multiple Vendor Invoices routine (as opposed to accessing this routine directly from the Accounting menu), note that many fields on the screen are filled with default values generated by responses you made in that routine. Some of the field documentation in this topic assumes no values were entered into a particular field and instructs you on how to enter a response. You can ignore these instructions. The basic functionality of this routine is the same regardless of how you access it.

If you select the Toggle Currency option before you choose the View Payments option, payments display in domestic currency.

General

This is a read-only routine. The documentation below describes the entry version of this routine, and appears here for reference purposes only.

Company Company

Specify an expense company for this transaction. The following scenarios affect your response to this prompt.

If you are using multi-company processing (specified at the Multi Company Processing field on the Advanced Setting tab in the General System Control Settings), and the AP Prompt for Company field is checked (in the Payables Control Settings file), then you must manually enter the expense company for this AP bill.

If you are using multi-company processing and the AP Prompt for Company field is NOT checked in the Payables Control Settings, the contents of the Company field (next to the AP Prompt for Company field) defaults here.

If you are NOT using multi-company processing, the default expense company appears here.

Date DateEnter the AP transaction date (that is, the current date). If editing an existing bill and STORIS AP Processing is active, you can edit the date that appears. Note that the date in this field must be from an open sales period.

Status Status

The current or last status of the AP bill appears to the right of the field. To change the status, click on the arrow to the right of the field and choose from the following list of statuses:

Null - Open

C - Closed

H - Hold

P - Pending

D - Deleted (Closed only)

Hold Code Hold Code

Enter a hold code (if any) for the AP bill. If you click on the arrow, a list of hold codes appears from which you can choose. This field is active only when the Status field is set to Hold.

Type Type

Specify the AP bill type. You have the following options:

02 - Expense

03 - Freight

12 - Expense Return

13 - Freight Return

This field is active only when creating expense bills, and then it inactivates after you specify a vendor. Otherwise, it is inactive and used for display only (the selection from the Select Process Desired field in the Enter Multiple Vendor Invoices appears).

NOTE: When creating freight bills, if the Freight in Terms Amount field is not checked in the Payables Control Settings, the system defaults the pay date instead of the terms date.

Vendor VendorThe vendor to whom payment is due appears.

Invoice Date Invoice DateEnter or select (from the drop-down calendar) the date of the invoice or credit received from the vendor.

Terms Code Terms Code

The AP Terms Code defaults from the first line item of the purchase order, if available.

If using STORIS AP Processing, you can edit the terms via the Terms field on Check Processing tab.

If using TPA, this field is available only if approving debit items. If you click on the arrow to the right of the field, you can choose from the list of terms codes that appears.

Freight Amount Freight AmountIf the invoice contains freight charges, enter the freight amount into this field. The system assigns these charges to the payables company.

Sales Tax Amount Sales Tax AmountIf the invoice contains sales tax charges, enter the sales tax in this field. The system assigns these charges to the payables company.

Miscellaneous Amount Miscellaneous AmountUse this field to enter any miscellaneous charges from this invoice. You can enter a negative amount. The system assigns these charges to the payables company.

Total Invoice Amount Total Invoice AmountAs items are approved, this field reflects the total invoice amount or total credit amount approved. The total invoice amount also includes freight, sales tax, and miscellaneous amounts, if any were entered from the invoice.

Exchange Rate Exchange RateThe exchange rate appears. Use this field to enter a new exchange rate for bills for foreign vendors. Whenever you change the exchange rate, the system recalculates all domestic amounts and updates the appropriate GL accounts. If using TPA, this field is active only for new bills. If using STORIS AP Processing, this field is active only for unpaid bills.

The Terms Amount and the Open Amount for the selected bill display at the bottom of this tab.

NOTE: If using TPA, when deleting un-transmitted approvals, the only options available are Delete (to delete selected invoices) and Exit (to exit the program without deleting the un-transmitted invoices selected).

Payment

Bank Bank

Enter the check print bank. The default bank from the Vendor Remit-To Settings displays, if any. If not, the default bank from the Vendor Settings displays, if any. Alternate Payment Method

Use these fields to select a manual payment method. To access these fields, a check must appear at the Select alternate payment methods during vendor invoice entry field in the Extended Security section of the User file for the log-on user.

Method Method

Select the method of manual payment. You have the following options:

Manual Check - Credits the Bank Payables Cash GL account.

Debit Card – Is treated the same as a manual check for GL purposes.

Cash – Credits the Paid with Cash GL account.

Credit Card - Credits the Paid with Credit Card GL account.

On Line – No GL hit required until the payment date. At that time, it is treated the same as a manual check for GL purposes

NOTE: Only the Manual Check and Cash options are available for payment on refund bills.

Once you make a selection at the Method field, the following fields activate:

Reference Reference

Enter a payment reference, up to 25 characters of alphanumeric text. This is a required field. The following are examples:

manual check number (must be numeric)

debit card number (perhaps last 4 digits)

cash text specified by user

credit card number (perhaps last 4 digits)

on-line bank reference

Date DateEnter the payment date. This is a required field. For on-line payments, this is the delivery date. You can enter a past date as long as it's not in a closed sales period.

Amount Amount

Enter the payment amount.
