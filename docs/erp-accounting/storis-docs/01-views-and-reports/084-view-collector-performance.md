Access

Accounting > Collections > View Collector Performance

Use this routine to display performance summary information for a selected collector. The screen displays period-to-date and year-to-date dollars collected for each aging category. If quotas exist for the collector (specified in the Collector Settings), the screen also indicates if quotas were met. The screen also displays money collected today and yesterday, and collection letter request information for today, yesterday, and month-to-date.

NOTE: This inquiry is also available as a dynamic escape.

Collector CollectorEnter the code of the collector whose performance you want to view. If you click on the Search button, a list of collectors appears from which you can choose. Note that if accessing from another routine instead of a menu, the collector defaults from the other routine and you cannot edit this field.

Period to Date

For each of the collections periods (for example, 1-30 days), the following information displays:

Quota

Amount collected period-to-date

Percentage above or below quota

Year to Date

For each of the collections periods (for example, 1-30 days), the following information displays:

Quota

Amount collected year-to-date

Percentage above or below quota

Collected

The dollar amounts collected for the current day and previous day display.

Letters

The number of letters requested for the current day, previous day, and period-to-date displays.
