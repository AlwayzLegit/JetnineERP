AccessAccess

Accounting > Revolving Receivables > Revolving Views and Reports > Revolving Reports > Report Projected Fixed Term Revolving Cash Flow

Use this routine to report the projected receipt of payments from fixed term revolving plans during the next 30, 60, 90, 180, 270, 360 days and the amount expected to be received after 1 year. Selection is by district or store. The report is generated in summary format only. It is sorted and sub-totaled by district and store, and includes grand totals.

District District

You can restrict this report to one, multiple, or all districts. If you click on the Arrow button, you can select a district from the list. If you click the Action button, you access the Multiple District Selection Window, from which you can choose one or more districts to report. If you enter one or more districts at this field, you de-activate the Store field below.

Store Store

You can restrict this report to one, multiple, or all store locations. If you click on the Arrow button, you can select a store from the list. If you click the Action button, you access the Multiple Location Selection Window, from which you can choose one or more store locations to report. If you enter one or more stores at this field, you de-activate the District field above.

Send Output to Send Output toThe output destination of the report displays. To change the output destination, click on the Actions button and select Output Settings.

Export Path Export PathIf you select either the Personal Report Viewer (PRV), Excel Export, or ASCII Export, this field displays the pre-set computer drive and folder location to which the system exports the report data. You cannot edit the export path using this process.
