Access

Accounting > Financing > View Current Financing Activity

Accounting > Financing > Financing Views and Reports > Financing Views > View Current Financing Activity

This inquiry provides information about transactions that are unresolved within one or more open batches. Inquiry can be by either Payment Type or by Finance Provider and Batch Date. A filter is also available to further limit the grid display.

Filter Selection Filter SelectionYou may select a filter option from the drop-down list at this field , or leave the field set to 0 (No Filter). Select Customer Code Filter to limit the display to a specific customer code. Select Name Filter to limit the display to a specific customer name. Select Reference Filter to limit the display to a specific transaction reference number. Select House Account# Filter to limit the display to a specific finance house account number.

Filter FilterIf a Filter Selection was chosen, this field must be used to indicate the specific Customer Code, Name, Reference number, or House Account number to use as a filter.

Plan Plan

To inquire by a specific plan, enter a valid Financing Payment Plan Settings (3rd Party Payment Type). You may click the Search button at this field to select from a list of valid payment types. Following selection of the plan, press the Enter or Tab key. The Batch Selection window displays.

Finance Provider Finance ProviderTo inquire by a specific 3rd party financing provider, enter the Finance Provider code. You may click the Search button at this field to select from a list of valid Finance Providers. If a finance provider is selected, entry of the Batch Date is mandatory.

Batch Date Batch DateIf a finance provider was selected, entry of the Batch Date is mandatory. Click the calendar icon at this field to select a date and then press the Enter or Tab key. The Batch Selection window displays.

Open Balance Open BalanceThe total open balance for the selected batches displays.

On Account On AccountThe total amount of on-account money for the selected batches displays.

Grid InformationGrid Information

The grid displays the following for each transaction displayed:

Reference

Customer Code

Activity Date

Amount - The transaction amount.

Fee - Usage fee amount.

Dispute - The dispute status displays as either Y (yes) or N (no).

Due Date - The date that the Amount Due is to be paid by the Finance Provider.

Amount Due - Amount due from the finance provider for the open transactions within the selected batches.

Plan

For additional information on a line item, double-click on it. The Transaction Detail screen appears with detailed information on the selected transaction.

NOTE: The Customer column displays either the customer name or the customer code, depending the Display Customer Name field in the Financing Control Settings. Also note that if set to display customer codes, the system displays on-account transactions as ON ACCNT.
