View a Customer's Current Balance Details > Double-click on a line in the grid

This screen displays when you double-click on a grid item in the View a Customer's Current Balance Details routine. Use this screen to view detailed information on the selected item.

The header displays the following fields:

Reference

Due Date

Dispute - displays only if transaction is in dispute

Amount

Grid InformationGrid Information

The grid is sortable and displays the following fields:

Transaction Type

Memo Reference

Date

Debit

Credit

Balance
