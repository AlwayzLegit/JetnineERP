This screen appears when you enter a customer finance account number that has already been assigned to one or more customers, for example in the View Available Financed Credit routine. The grid lists all customers assigned to the account number. To select a customer from the grid, highlight a grid line and click on Continue. Otherwise, click on Exit to return to the main screen.

NOTE: The Multiple Customers Per Finance Account field in the Financing Control Settings must be active for this screen to appear.
