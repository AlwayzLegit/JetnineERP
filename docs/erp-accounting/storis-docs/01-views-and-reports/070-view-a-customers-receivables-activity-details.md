Access

View a Customer's Receivables Activity Summary > check boxes on grid rows, click Select button

Use this routine to view detailed transactions related to the selections made on the summary screen. Initially, the earliest date is set to the first day of the current month and the latest date is today's date. Another date range can be selected. You can filter the data displayed in the grid using the Search and Find features.

Earliest EarliestThe first day of the current month displays in this field and can be edited. Click the calendar icon to select a different date. Transactions that occurred before this date are not displayed.

Latest LatestToday's date displays in this field and can be edited. Click the calendar icon to select a different date. Transactions that occurred after this date are not displayed.

NOTE: If you change the earliest and/or latest date (above), click the Find button to refresh the grid display using the new date range.

Search SearchYou can use this field to filter the grid data. Enter the data to use as search criteria and then click the Find button to refresh the grid display. You can enter a portion of the Activity Type, Date, Reference, etc. For example, to filter the display to view only transactions with an Activity Type of "I/R Cycle - Interest" or "R/R Cycle Interest", you can enter "interest" in this field and then click Find.

FindFind

Use the Find button to refresh the grid display using the selected search criteria. Each time you change a date or enter a new Search filter, you must click this button to display the results in the grid.

Grid InformationGrid Information

The grid displays detailed information about the selected contracts, plans, and open item receivables. You can filter the grid information by changing the date range and/or entering criteria at the Search field. The following data columns display in the grid. If a line is selected that references a sales order, return, exchange or adjustment,you are taken to View an Existing Sales Order for further information.

Activity Type - This column describes the type of activity. The description displayed is either the user-defined description you entered via Receivables Activity Type Settings, or the standard STORIS description.

Date - The transaction date for the activity displays.

Reference - The reference number for the transaction displays.

Memo Reference - This column displays the memo reference, if any, entered for the transaction.

Activity - The long term and short term activity amount displays here. Credit amounts are indicated with a negative sign.

Balance - The balance at the time the transaction was posted displays in this column. Credit balances are indicated with a negative sign.

Short Term Effect - The net effect of the transaction on the short term balance is displayed. This is for extended receivables.

Long Term Effect - The net effect of the transaction on the long term balanced is displayed. This is for extended receivables.
