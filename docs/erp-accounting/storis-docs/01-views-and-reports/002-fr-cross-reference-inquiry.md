This screen appears when you attempt to assign to a customer a finance account number that has already been assigned to another customer, for example during the payment entry process. The grid lists all customers previously assigned to the account number. To select a customer from the grid, highlight a grid line and click on Continue. Otherwise, click on Exit to return to the main screen.

NOTE: The Multiple Customers Per Finance Account field in the Financing Control Settings must be selected for this screen to appear.
