Access

Use this routine to view detailed information for active and pending revolving plans for the selected customer. This is a read-only screen that you use to view the plan information only. To maintain a revolving plan for a customer, use the Enter a Customer's Revolving Terms & Conditions routine.

Customer Customer

Once the customer is selected, the Cell Phone, Home Phone, Work Phone, Ext, and Email Address fields populate. These fields are read-only.

Plan Plan

Specify the code of the revolving plan to view. You can click the Arrow button to select a code from the list of active and pending plans for this customer.

Co-signer, Co-applicantCo-signer, Co-applicantIf the customer's request for credit includes a co-signer, the customer ID and name is displayed below the customer name. If a co-applicant exists, the name displays below the customer name.

If the customer's request for credit includes a co-signer, the customer ID and name is displayed below the customer name. If a co-applicant exists, the name displays below the customer name.

Plan

Current DueCurrent DueThe amount currently due from the customer for this plan is displayed.

Standard MMPStandard MMP

The calculated MMP (Minimum Monthly Payment) amount for this plan displays. For plans that are set to calculate the MMP based on a percentage, this field displays the lowest MMP amount allowed for this plan.

NOTE: For more information on how the MMP is calculated, visit Revolving Plan Settings.

Total BalanceTotal BalanceThe total revolving amount due for the plan displays. This is the sum of the long term and short term amounts due.

Highest BalanceHighest BalanceThis field displays the highest amount that the customer's revolving balance has ever been since the plan became active.

Last CycledLast CycledThe date the revolving account was last cycled displays.

InsuranceInsurance

If insurance was purchased with this revolving plan, the insurance code displays here.

Last PaymentLast PaymentThe date and amount of the last credit/payment to the customer's account is displayed. This amount includes customer returns.
If an amount exists, description text displays the date of the last payment. If no payment exists, no description text is shown.

Last ChargeLast ChargeThe date and amount of the last charge to the customer's account is displayed.
If an amount exists, description text displays the date of the last charge. If no payment exists, no description text is shown.

Activated/PendingActivated/Pending

The date this plan was activated or the date the pending plan was created displays.

Closed ClosedThis field is visible only for existing plans. If you entered a closed date for the plan via Enter a Customer's Revolving Terms & Conditions, the date on which the plan was terminated or the date the plan is due to be terminated displays here.

ReasonReasonIf the plan was closed, the reason for the termination is displayed. The closed date and reason code are entered via Enter a Customer's Revolving Terms & Conditions. If the plan is not closed, this field is hidden.

Fixed TermFixed TermFor fixed term plans, the number of term months is displayed from the plan settings. This field is hidden if not applicable to the selected plan for this customer.

% of Balance% of BalanceThis field is blank for plans that determine the MMP based on a fixed term or fixed MMP. If the plan calculates the MMP using a percentage (of the plan balance), the percentage from the plan settings displays here.

RemarksRemarksRevolving plan remarks are displayed.

Customer

Store LocationStore LocationThe customer's store location displays.

Due DayDue DayThe customer's due day (1-28) displays, based on customer, location, and control settings. For information on how the due day is determined, see the Due Day field in Advanced Customer Settings.

Prepay Amount Prepay AmountPrepaid MMP amounts entered via Enter a Customer Payment, if any, display here.

Year to Date

Finance Charge Finance ChargeThe total amount of finance charges assessed year to date for this plan displays here.

Insurance InsuranceThe total insurance amount charged year to date for this plan displays here.

Late Fees Late FeesThe total amount of late fees assessed year to date for this plan displays here.

Fees FeesThe total amount of other fees (finance charge fee, etc.) assessed year to date for this plan displays here.

Credit

Credit LimitCredit LimitThe customer's credit limit, if any, displays in this field. If no limit was set, OPEN displays here.

ReceivablesReceivablesThe customer's A/R balance is displayed.

Potential ReceivablesPotential ReceivablesThe total open order balance due for this customer is displayed.

Available CreditAvailable CreditThe amount of credit currently available to this customer displays.

CommentsComments

If Account Comments were entered for this customer via Customer Settings, the Comments button is active. When you click the Comments button, you access the read-only Customer Credit Comments window.

Plan SettingsPlan Settings

To view a read-only version of the Revolving Receivables Payment Plans screen, click the Plan Settings button.

Payment AgreementPayment Agreement

This extra action button is active only when an active plan with a payment agreement exists for this customer. Click the button to view the Enter Payment Agreement window in query mode.
