(As Of Customer Statement Print)

Access

Accounting > Receivables > Print Receivables Document > Print a Customer As Of Statement

Use this program to print "as of today" customer A/R statements. This statement details customer buying and payment history as of the current date. Printing options include store location, district, and customer code number.

NOTE: If no check appears at the Generate Zero Balance Statements field in the Account Statement Cycling Control Settings, the system restricts zero-balance statements regardless of activity. However, if you use this routine to print for a single customer, the system overrides that field and allows a zero-balance statement (if any) to print.

Location Location

Enter the location for which you want to print customer statements. If you click on the Action button , you can use the Multiple Location Selection window to choose one or more locations. Otherwise, leave the field blank to print statements for all locations.

District District

Enter the district for which you want to print customer statements. Otherwise, leave the field blank to print statements for all districts.

Customer Code Customer Code

Enter the code of the customer for which you want to print customer statements. If you click on the Search button, you access the Search for a Customer (Customer Code Lookup) screen from which you can search for customer codes.
