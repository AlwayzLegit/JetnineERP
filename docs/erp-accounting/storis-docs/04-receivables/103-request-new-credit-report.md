Access

Pending items - Credit Request Review Screen, click Request a New Credit Report button

Closed items - Credit Request Review Screen, click Submit a New Credit Request button

Use this routine to send a request to the credit bureau for a new credit report for the current review item or to submit a request for a new credit review item.

Request New Credit Report Window

When you click this action button, the system checks the status of the review item and whether a valid credit report exists.

If the credit review has not been completed, the following message displays in a text box at the top of the screen:

Credit review is not complete. The current credit report will be discarded and replaced with the new credit report.

If the credit review has been completed, the system performs a check to determine the age of the application linked to the closed review item. If too old, you must enter a new application. If the application is current, the system copies it into the new application where you can edit it. The following message appears:

Credit review is complete. A new review item will be created to which the new credit report will be linked. A new application is required. The new credit review item will not be associated with any order.

Create New Credit Request Review Window

Use this screen to create a new review item based on the currently displayed closed item. This action is active only if you are inquiring on a closed credit request (via the View Credit Request Responses or View Completed Credit Requests routines).

NOTE: If you do not have access to existing credit application data via your User/User Group settings, you can still use this screen to request a new review item. The screen prompts for verification of the applicant's social security number. You cannot proceed with the request until the social security number is entered. (See below.)

A new review item is created to which a credit application and credit report must be linked. As with the New Credit Report extra action, the system checks to determine the age of the application linked to the closed review item and if too old, you must enter a new application. If the application is current, the program copies it into the new application where you can edit it. Additionally, the system checks to determine the age of the credit report linked to the closed review item and if too old, pulls a new credit report. The following message displays:

Credit review is complete. A new review item will be created to which the existing credit report will be linked. If the existing credit report is no longer valid, a new report will be pulled.

The screen also offers the following options:

Credit Bureau Credit Bureau

The bureau code defaults from the application. If you click the arrow button, a list of active credit bureaus appears, from which you can select a code.

Update Credit Application Update Credit Application

When the box at this field is checked, you access the Credit Application Entry screen when you click the Save button on this screen. The field is checked and inactive if reviewing a closed item with a linked credit application that has exceeded the numbers of days set in the Credit Application Control Settings.

Retain Original Comments Retain Original Comments

If checked, the audit comments from the closed review item are copied to the new review item.

Social Security # Social Security #

This field is used for verification of the customer's social security number. The field is active only if the reviewer does not have access to view existing credit application data via the Access Other Credit Applications and Score Reporting field in their User/User Group settings. The customer's social security number must be entered in order to proceed.

Comment Comment

Up to 70 characters can be entered to add manual comments for this review item. You can view manually entered and system entered comments entered via the Credit Request Review Screen, by clicking the extra action button called Audit Request Activity.
