Access

Installment Receivables > Manage and Adjust Installment Contracts > Review Contract Details button > Search button at Insurance field

Use this routine to view the insurance plans associated with an installment plan.

Grid InformationGrid Information

Code - This field displays the code of the insurance plan.

Description - This field displays the description of the insurance plan.

$ Amount - This field displays the amount of the insurance plan in that row.
