Access

Apply NSF and Correct Misapplied Payments > Select a payment from the grid > Click on Add.

Use this screen to proceed with the payment update specified in the Apply NSF and Correct Misapplied Payments routine. You can also view comments associated with the transaction.

Proceed With Update Proceed With Update

To proceed with the update, check the box. Otherwise, leave the box blank.

NOTE: For misapplied payment adjustments, use the Enter a Customer Payment program to apply the reversed payment.
