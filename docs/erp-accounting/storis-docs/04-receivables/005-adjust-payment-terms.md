Access

Receivables > Installment Receivables > Manage and Adjust Installment Contracts > Adjust Payment Terms button

Receivables > Installment Receivables > Manage and Adjust Installment Contracts > Review Contract Details button > Adjust Payment Terms button

Use this routine to make various changes to the payment terms of a contract such as due day, grace days, extensions, same as cash date, and reverse payment.

This screen is available for active contracts and if a user has security via Installment; Exclude Contracts from Auto Pay in the receivables security settings then it is also available for pending contracts.

Contract Contract

The contract number displays here.

Due Day Due Day

Use this field to specify a new due day from the drop down.

Add Grace Days Add Grace Days

Use this field to add grace days to an installment term. You may select a value from 1 to 30.

NOTE: In order to make a change to this field, you need to have Installment; Add Contract Grace Days enabled in the receivables security settings, or you must obtain a security override from an authorized user.

Extend Months Extend Months

Use this field to extend the number of months in the installment contract's term. You may select a value from 1 to 12.

NOTE: In order to make a change to this field, you need to have Installment; Extend Contract's Number of Months enabled in the receivables security settings, or you must obtain a security override from an authorized user.

Total $ Keyed-off Total $ Keyed-off

This field is read-only and displays the total keyed-off amount.

Credit ReversalCredit Reversal

Use this field to enter the credit amount. This field is only active when there is a value in the Total $ Keyed-off amount field.

Same as CashSame as Cash

If there is a same as cash date on the contract, the date displays at this field.

Exclude Contract from Auto PayExclude Contract from Auto Pay

To exclude the selected installment contract from auto pay, check the box at this field. Otherwise, leave the box blank. To access this field, the user must have Installment; Exclude Contracts from Auto Pay enabled in the receivables security settings.

Revoked Revoked

Click this check box to remove the expiration date for the same as cash agreement for this contract. The check box is only active if there is a Same as Cash date and the date is in the future.

Comments Comments

Clicking the actions button at this field brings up the Text Entry Screen where you can enter comments pertaining to the contract.

Comments are required when making a change to the payment terms of a contract.

Actions

G/L Account Maintenance - Select this option to access the G/L Distribution screen, where you can maintain G/L accounts for installment contracts.
