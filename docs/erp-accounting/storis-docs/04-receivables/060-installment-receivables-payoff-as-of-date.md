Access

Receivables > Installment Receivables> Manage and Adjust Installment Contracts > Update Contract Status button > selecting cancel from the status field

Receivables > Installment Receivables> Manage and Adjust Installment Contracts > Review Contract Details > Update Contract Status button > selecting cancel from the status field

Use this screen to enter an effective payoff date for an installment plan. The date can be in the future if the PAYOFF/CANCELLATION DATE - Allow Future Dates setting is checked in Installment Receivables Control Settings.

If contract payments are accessed late and Revoke Same as Cash After ___ Late Fees in Installment Payment Plan Settings is enabled, a warning message is displayed and valid credentials must be entered to continue. You have the ability to proceed when Override Revoke Same as Cash Terms in Create a User/Group Actions - Receivables Security is enabled. If it is not enabled, managers credentials are needed to continue.

This display-only field reflects the number of late fees in the Revoke Same as Cash After ___ Late Fees field in Installment Payment Plan Settings.
