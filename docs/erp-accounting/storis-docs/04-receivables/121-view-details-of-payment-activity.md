Access

View a Customer's Payment Activity > Double-click on a line in the grid

This screen displays the detail of the customer's payment activity. It contains the total amount, how it was applied, and type of payment (ie. cash, check, credit card).

If payment was made by check, the check number is displayed. If payment was made by credit card, the last four digits of the credit card number are displayed.

Send Output To Send Output To

This display-only field shows the current output option to which this report or document will be sent. Click the Actions button and choose Output Settings to change this current output option.

S - Screen - Display the report output on the screen using Adobe Reader. If you do not have Adobe Acrobat ® loaded on your PC, you must download it. Note that in a given session, once you display a report using Acrobat Reader, you cannot display another unless you rename the existing report or delete it from Acrobat Reader.

P - Printer - Send the report output to the print spooler.

Export Path Export Path

This feature is not available on this screen.

Actions

Output Settings

Print Comments - Send the report to the output destination specified at the Send Output To field.

Reprint Receipt - Select this option to print or email a reprint of the receipt. During reprint, the output of account balances is replaced with 'Reprint' as the balances that were available at the time the original receipt was printed are not available during reprint. This option is not active for payments that have been misapplied or NSF'd.
