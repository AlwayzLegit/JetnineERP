Access

Revolving Payment Estimator > Sales Order Table button

Use this routine to view and select the terms and MMP amounts for the selected Per Sales Order plan in the Revolving Payment Estimator. If the Monthly Payment and Term Months fields are active on the Revolving Payment Estimator screen, and you selected a Per Sales Order type plan in the Option field, the Sales Order Table button is displayed. Click the button to access this MMP Selection window. The applicable terms and MMP amounts display in a grid. Double-click to select a line. The selected amount and terms are displayed in the Monthly Payment and Term Months field on the estimator screen.

Months Months

This column displays the term months (2, 3, 6, 12, 18, 24, 36, 48, 60) in ascending order. When you finance an order with a Per Sales Order plan, this table can help you determine the MMP amount and corresponding term months.

Projected MMP Amount Projected MMP Amount

This column displays the minimum monthly payment amounts for each of the terms in descending order. When you are financing an order with a Per Sales Order plan, viewing this table helps you determine the term months and MMP amount.
