Access

Customer > Point of Sale > Returns and Refund

Use this screen to search and display completed exchanges, returns, credit adjustments, payments made on account and manual credit memos on completed orders that have resulted in an accounts receivable credit. Enter your search criteria in the provided fields and click Search. The results populate in the grid. In order to complete the refund, double-click a row in the grid to open the Process Receivables tab of Enter a Customer Payment/Refund/Gift Certificate then follow the appropriate steps to complete the refund.

Start DateStart Date

Enter the start date of your order search or click the calendar icon to select the start date from a calendar. Date cannot be in the future.

End DateEnd Date

Enter the end date of your order search or click the calendar icon to select the start date from a calendar. Date cannot be in the future.

LocationLocation

Use the drop-down menu to choose a single location or click the Actions button to choose multiple locations. If multiple locations are selected, an ellipsis ("...") displays in the Location field. Leaving this field blank selects all locations.

Payment Type CodePayment Type Code

Use this field to select credits where this payment type has been used on the original order. One or more payment types can be selected.

If a payment type is specified here, manual credit memos do not display in the grid. This is because payment types are not used when a manual credit memo is generated.

Credit Card On Original OrderCredit Card On Original Order

Check the box to limit results to original orders that included credit card payments. This setting does not apply to payments made on account or manual credit memos.

If you want to see credit card payment types on all types of credit balances, use the Payment Type Code search.

SearchSearch

Click the Search button to execute your search.

Grid InformationGrid Information

Search results populate in this grid. To process the refund, use the corresponding Refund option. This grid can be filtered.

Reference - The original order number.

Refund - Use this column to process the refund for this line. When invoked, the Process Receivables tab of Enter a Customer Payment/Refund/Gift Certificate is accessed, where the refund can be processed by choosing a method in the Issue Refund By section. Upon completion, you are returned to the Maintain Order Credits screen where your search results are repopulated based on the current search criteria.

View Order - Invoke this extra action to call the View an Existing Sales Order process, where the original order information can be reviewed. Note that this extra action is not applicable to payments made on account and manual credit memos.

Return - The return number, if applicable. If multiple returns are referenced on the original order, the word 'Multiple' displays here. If desired, add a dynamic escape to View Customer Activity to view the generated returns.

Location - The location from which the order originated.

Customer - The customer code.

Customer Name - Name of the customer.

Credit Amount - The amount of credit for the customer.

Last Activity Date - The date of the last time the customer had an order completed or made a payment on an open item. This does not include new open orders or application of deposit on open orders.

Payment Type - The associated payment type, if applicable. For more than one payment code, the word 'Multiple' displays. Use the associated View Payment column to view the multiple payment types.

View Payment - Invoke this button to view more information about this payment via the Payment Information screen.

Billing Address 1 - The first line of the customer's billing address.

Billing Address 2 - The second line of the customer's billing address.

Billing City - The city of the customer's billing address.

Billing State -The state of the customer's billing address.

Billing Zip - The zip/postal code of the customer's billing address.
