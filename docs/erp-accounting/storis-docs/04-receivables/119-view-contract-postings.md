AccessAccess

Installment Receivables > Manage and Adjust Installment Contracts > Review Contract Details button > Search button by Postings field

Use this screen to view the postings to the selected installment contract.

Grid InformationGrid Information

Date - This field displays the date of the posting in that row.

Allocation - This field displays where the money for a particular posting was applied.

Adjustment - This field displays the amount of the posting.

The grand total line displays the total amount of all postings in the grid.
