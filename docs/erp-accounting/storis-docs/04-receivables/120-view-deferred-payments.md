Access

Installment Receivables > Manage and Adjust Installment Contracts > Review Contract Details button > Search button by Deferred field

Use this routine to view the deferred payments for the selected installment contract.

Deferred Payments Deferred Payments

The total amount of all deferred payments displays here.

Deferment Fee Deferment Fee

The total amount of deferment fees displays here.

Grid InformationGrid Information

Deferred Date - The date of the deferment displays here.

$ Deferment Fee - The amount of the deferment fee displays here.

Reference - The reference number associated with the deferment displays here.

Due Date - The original due date for the deferred payment displays here.

Memo Reference - The reference number for the original payment due before the deferment displays here.
