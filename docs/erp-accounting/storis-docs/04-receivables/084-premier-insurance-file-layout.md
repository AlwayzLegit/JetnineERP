The following templates are used for Premier Insurance.

Insurance Enrollment - The insurance enrollment file notifies the insurance provider when insurance has been added or removed from a revolving account.

Column Field Name Description
A Account Number Customer Number
B Account Status Active or Cancelled
C Status Date Reporting
D Account Holder First Name Customer First Name
E Account Holder Last Name Customer Last Name
F Date of Birth Customer Date of Birth
H Address 1 Customer First Address
I Address 2 Customer Second Address
J City Customer City
K State Customer State
L Zip Code Customer Zip Code
M Phone Customer Phone Number
N Email Customer Email Address
O DPP Enrollment Date Activation Date
P DPP Plan Code Insurance Code
Q DPP Cancellation Plan Cancellation Date
R Revolving Plan Revolving Plan Code

Insurance Premium - This file informs the insurance provider that was charged during cycle processing.

Column Field Name Description
A Account Number Customer Number
B Status Date Reporting Date
C Account Holder First Name Customer First Name
D Account Holder Last Name Customer Last Name
E Date of Birth Customer Date of Birth
F Address 1 Customer First Address
H Address 2 Customer Second Address
I City Customer City
J State Customer State
K Zip Code Customer Zip Code
L Phone Customer Phone Number
M Email Customer Email Address
N DPP Plan Code Insurance Code
O Statement Outstanding Balance Current Balance
P Statement as of Date Date of monthly statement being reported.
Q Minimum Payment Due Minimum Monthly Amount
R Minimum Payment Due Date Monthly Due Date
S DPP Plan Fees Charged Protection Plan Fees
T Interest Fees Interest Amount
U Late Charges Late Fees
V Last Payment Date Last Payment Date
W Revolving Plan Revolving Plan Code
