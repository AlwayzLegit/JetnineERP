Access

Indicate Message to Print on Customer Statements, leave the Message Code field blank, click the Manage Criteria Assignment extra action button

Use this routine to view and maintain statement message assignments by criteria.

Plan Plan

You can use this field to maintain message assignments for this criterion. If you click the Arrow button you can select a single revolving plan from the drop-down list. If you leave this field blank, you are selecting All plans.

State State

You can use this field to maintain message assignments for this criterion. If you click the Arrow button you can select a single state from the drop-down list. If you leave this field blank, you are selecting All states. If you indicate a specific state, the Store field becomes inactive.

Store Store

You can use this field to maintain message assignments for this criterion. If you click the Arrow button you can select a single store from the drop-down list. If you leave this field blank, you are selecting all stores. If you indicate a specific store, the State field becomes inactive.

Once you have indicated your choices in the Plan, State, and Store fields, click the Select button. Available messages are listed in the grid. (See Grid Detail below.)

Grid InformationGrid Information

The grid displays all available messages.

Messages assigned to the criteria you selected are marked with a checked box.

You can remove an assigned message by removing the check from the box.

To assign a message to the selected criteria, check the box.

To check all the boxes, click the All button.

To clear all checked boxes, click the None button.

Click the Save button to update your changes.
