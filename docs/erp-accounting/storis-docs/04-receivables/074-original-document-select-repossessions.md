Access

Use this screen as the second step of the Repossession process. In this step, items sold on the same line item are grouped on a single grid line with the returned quantity indicated in the Selected column of the grid.

Customer Customer

The customer specified on the previous screen displays.

Product Product

Enter the code of the product you want to repossess. If the product you specify exists in the grid, the program selects the first line in the grid containing that product. You can also double-click on a grid item to select it. If the camera icon to the right of the field is active, you can click on it to view a picture of the specified product. If the camera is dimmed, no image exists for the product at this time.

Repossessed Quantity Repossessed Quantity

Once you specify a product, this field displays the number of items from the sales order line item selected on the previous screen. You can edit this quantity with any number between 0 and the number of items available for return on the line. Previously returned items are not available. To update the grid with your change, click on the Add button. To abandon your changes, click on the Clear button.

NOTE: The Remove and Delete buttons are inactive on this screen.
