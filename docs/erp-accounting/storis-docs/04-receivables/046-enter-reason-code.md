Access

Enter a Customer's Revolving Terms & Conditions, click Actions button, select Close Reason

Use this window to indicate the reason you are closing the installment or revolving plan.

Enter Reason Code

Reason Reason

Enter the reason code in this field. To search for a code, click the Search button to select from a list of reason codes.

Comment Comment

Enter comment text to explain the reason for a plan closure.
