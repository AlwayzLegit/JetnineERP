Access

via the Collector Review Process.

Use this screen to process Collections information. When a valid customer code appears in the Customer field, the customer's available information displays. For the selected customer, you can

assign a promise-to-pay date and amount,

assign a call back date and time,

request collections letters be sent,

update the collector comments,

reassign a customer to a different collector, or

review collector performance.

NOTE: If account comments (specified on the Point of Sale tab in the Advanced Customer Settings) exist for the selected customer, they display in a pop-up window when you first access this screen.

If your user/user group receivables setting Collector Review; Automatic Display of Customer User Defined Settings is enabled, the User Defined Settings entry screen automatically displays when you first access this screen.

Customer Customer

Enter the code of the customer whose Collections information you want to view and/or edit. If you click on the Search button, the Search for a Customer screen appears from which you can select a customer.

This field is active only if you access this screen via the Customer option at the Function field on the Collector Review Process screen. Otherwise, the customer defaults from that screen and you cannot edit this field.

Due Due

The amounts due for the customer display.

Credit Credit

The credit amounts for the customer display.

Select the reassign button to reassign the selected customer to another collector. You can also use this button to remove the customer from Collections.

Click the Promise button to enter a promise to pay date and amount.

Click the Letter button to specify a collections letter to send to the selected customer.

To view or edit the Customer Collections Review Log, click on the Comments button.

To assign the date and time you want the Collector to contact the selected customer, click the Contact button. If a contact date and time already exists for the customer, it displays to the right of the button.

Last Contact Last Contact

The date (if any) of the last contact with the customer displays.

Collector Collector

The collector assigned to the customer displays.

Payment

Monthly Statement PerformanceMonthly Statement Performance

A code displays indicating the customer's monthly statement performance for each of the last 12 months.

Action Action

Select the action (if any) you want to perform. You have the following options. If you select anything other than None Selected, you activate the Save button, and when you click on Save, the following updates occur based on your selection:

None Selected

Spoke to Customer – The Last Contact Date and Last Collections Activity dates in the CUSTOMER.CREDIT file update with the current system date.

Left Message – The Last Collections Activity date in the CUSTOMER.CREDIT file updates with the current system date.

No Answer – The Last Collections Activity date in the CUSTOMER.CREDIT file updates with the current system date.
