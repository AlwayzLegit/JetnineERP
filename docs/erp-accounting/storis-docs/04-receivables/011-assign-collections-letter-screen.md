Access

via the Letter button on the Collector Review - Customer Update Screen.

Use this screen to specify a collections letter to send to the selected customer. The name of the letter you select appears in the customer’s Collections Comments file.

Collections Letter Collections Letter

Specify the collections letter you want to send to the selected customer. If you click on the Arrow, a list of collections letters appears from which you can choose.

Print Now Print Now

To print the letter immediately, check the box at this field. Otherwise, leave the field blank. If you leave this field blank, the system prints the letter as part of the first End-of-Day process that occurs after you assign the letter for printing.

This field is active only if generating Collections letters via the Enhanced Laser option (specified at the Collections Letter field in the Collections Processing Control Settings), and your PC is set up for Enhanced Laser Printing.
