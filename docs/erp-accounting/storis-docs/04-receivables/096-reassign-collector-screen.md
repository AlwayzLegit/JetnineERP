Access

via the Reassign button on the Collector Review - Customer Update Screen.

Use this screen to manually reassign customers from the current collector to a new collector. You can also use this screen to remove customers from Collections.

NOTE: This screen is active only for collectors whose Allow Manual Assignment field in the Collector Settings is enabled.

If you assign a new collector or remove the customer from Collections, the edits appear in the customer's Collections Comments file.

Current Collector Current Collector

The current collector displays.

New Collector New Collector

Enter the code of the new collector you want to assign to the customer. If you click on the Search button, a list of collectors appears from which you can choose. If a check appears at the Remove field, this field is inactive.

Remove Remove

To manually remove the customer from Collections, check the box at this field. Otherwise, leave the field blank.

If you check the box at this field, the program removes any entry in the New Collector field and inactivates the field.
