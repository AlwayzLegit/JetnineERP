AccessAccess

Installment Receivables > Manage and Adjust Installment Contracts > Merge / Refinance Contracts > Actions button > View A Customer's Payment Activity

Installment Receivables > Manage and Adjust Installment Contracts > Review Contract Details > Actions button > View A Customer's Payment Activity

Accounting > Receivables > Receivables Views and Reports > Receivables Views > View A Customer's Payment Activity

Accounting > Revolving Receivables > View A Customer's Payment Activity

This grid displays a customer's payment activity, including deposits, in ascending date order.

NOTE: This process can be used to view the refund method used to process a revolving credit refund.

Customer Customer

If you access this screen through the menu, enter the customer's number in this field or use Search for a Customer.

If you access this screen through the Actions button in Merge/Refinance Contracts or Review Contract Details, the screen is populated with the customer information from the installment contract.

Grid InformationGrid Information

The grid displays the customer's payment activity in ascending date order. You can click on the date to reverse the sort order.

Date - This field displays the transaction date.

Paid With - This field displays the payment type.

$ Amount - This field displays the payment amount, as well as the refund of deposits and payments.

Double click a line in the grid to View Details of Payment Activity.
