Access

Customer Credit and Scoring Information > click Action button at Registered Lien Details field

Use this routine to view and maintain registered lien information for a customer. If you have the "Update Customer lien requests" field enabled in your receivables security settings, you can edit lien registration information on this screen. If you do not have this permission, you can view the information in the grid, but cannot edit it.

If you have the security access to edit the information in the grid, you can enter registered liens for this customer, edit existing lien information such as the registration number, dates, and reference, and you can click the Remove button to delete a line in the grid.

Registration Number Registration Number

This is the number assigned when you registered the lien. Up to 12 alphanumeric characters can be entered in this column and the number must be unique.

Registration Date Registration Date

When adding a lien registration, you must enter the date of registration for this lien.

Expiration Date Expiration Date

When adding a lien registration, you must enter the date of expiration for this lien.

Reference Reference

When adding a lien registration, you must select a reference number.

Grid InformationGrid Information

The following columns are displayed in the grid:

Registration Number

Registration Date

Expiration Date

Reference

Remove

To delete a line in the grid, click the Remove button.
