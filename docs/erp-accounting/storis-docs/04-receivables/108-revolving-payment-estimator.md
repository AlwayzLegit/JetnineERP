Access

Accounting > Revolving Receivables > Revolving Payment Estimator

Enter a Sales Order > Payment page > Actions button

Enter a Shopping Cart > Actions button

View All Installment Activity for a Customer > Payment Estimator button

Use this routine to provide a comparison of up to 3 revolving plan options. This process displays the terms defined in Revolving Payment Plan Settings for each plan selected, including entries for the order amount and deposit amount. The minimum monthly payment amount (MMP) is automatically calculated and displayed for the Full Plan. The MMP is an overall amount that includes the customer's current and pending balances.

· The estimator limits comparisons to available revolving plans based on plan dates and location restrictions. The location used for the location restrictions is based on how the estimator is accessed.

When accessed from the menu, the login location is used.

When accessed from the Enter a Sales Order process, the order's store location is used.

When accessed from the Enter a Shopping Cart process, the login location is used.

When accessed from the View All Revolving Plan Activity for a Customer, the login location is used.

This screen is used for estimations only! These are estimated calculations and may not accurately reflect revolving plan payments.

Option 1, 2, 3Option 1, 2, 3

If accessing the screen from a sales order and a plan was indicated on the order, that plan defaults in the Option 1 field (first column) when you initially access the estimator. Depending on your settings, these three fields fill in default plans and/or allow you to click the Arrow button to choose the plan from a drop-down list of available plans.

NOTE: The default values displayed in these fields depend on the Revolving Payment Estimator Defaults settings in Warehouse/Store Location Settings and Revolving Receivables Control Settings. If the revolving plan is pulled from an order, that plan is displayed in the Option 1 field regardless of the Revolving Payment Estimator Defaults settings. The ability to click the Arrow button and select another plan depends on the Allow Changes setting at each of the Option fields in Warehouse/Store Location Settings and Revolving Receivables Control Settings.

Order AmountOrder Amount

If accessing the screen from a sales order or shopping cart, this amount defaults from the order into all three Order Amount fields in the estimator and can be edited. If accessing this screen from the menu, you must enter the order amount.

Deposit AmountDeposit Amount

When accessing the estimator from a sales order and a deposit amount exists on the order, it is NOT used as a default on the estimator. If defined, the minimum deposit amount for the finance plan selected is used as the default. When accessing the estimator from the menu or from shopping cart entry, the minimum deposit amount restriction, if defined for the selected plan, is automatically defaulted after the order amount has been entered and can be overridden.

Finance AmountFinance Amount

The amount to be financed is calculated and displayed and cannot be directly edited. Changing the Order Amount and/or the Deposit Amount causes this field to be recalculated.

Promotional

If promotional financing is defined for the selected plan, the promotional interest rate and expiration date are displayed. Otherwise, these fields are hidden.

Interest RateInterest Rate

The interest rate percentage for the promotion displays from Revolving Payment Plan Settings.

Expiration DateExpiration Date

The date the promotion expires displays from Revolving Payment Plan Settings.

Full Plan

Monthly PaymentMonthly Payment

The minimum Monthly Payment amount (MMP) is automatically calculated and displayed for the Full Plan. The MMP is an overall MMP that also includes the customer's current and pending balances.

Term MonthsTerm Months

The number of term months used to estimate the plan payments is displayed.
