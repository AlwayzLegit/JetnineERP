Access

Enter a Customer Payment, Actions menu, Pre-Payment/Revolving Prepayment

Use this window to post revolving MMP prepayments. The option to post prepayments to revolving is available if the customer has at least one active revolving plan with a balance, and no MMP's currently due.

Transaction Transaction

A reference number with the prefix "PP" is automatically assigned for this transaction and displayed in this field.

$ $

Enter the amount of the revolving prepaid MMP.

Click Save to add this pre-payment to the grid on the main screen of Enter a Customer Payment.
