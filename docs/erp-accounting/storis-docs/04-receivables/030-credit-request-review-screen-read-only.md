AccessAccess

Double-click on a grid item in the View Credit Request Responses routine.

Double-click on a grid item in the View Completed Credit Requests routine.

This is the read-only version of the Credit Request Review Screen. You can view but not edit the information on the screen. The fields on this screen are identical to those on the Credit Request Review Screen, but access to the information depends on your security settings. In addition, the Print Status Letter extra actions option is available only from this read-only version of the screen. (See Actions button below.)

Security

When you access the read-only (view) version of the screen (via View Credit Request Responses or View Completed Credit Requests), the system checks the Access Other Credit Applications and Score Reporting field on the Extended Security tabs to determine if you have access to sensitive credit application information. If you do not, the credit score is masked and any global extra action buttons that display sensitive customer information (social security number, scoring, etc.) are inactive. If you have access via the security setting, you can access all customer information, including any credit score returned by the credit bureau.

ActionsActions

Print Letter - Use this option to print letters for completed or conditional requests for the selected customer. If the request has been conditionally approved at some point, the option to print the Conditional Approval letter appears. If you say Yes, the Conditional Approval letter prints. If you say No, the option to print the Approval or Decline letter appears. Note that this option is available only from the read-only version of the Credit Request Review Screen.
