(Collector Review Process)

Access

Accounting > Collections > Collector Review

Use this screen to process customer accounts assigned to Collections. You first specify a collector. Any customers assigned to the collector appear in the grid. Next, select the collections function you want to perform. Finally, select the customer for which to perform the collections function. Once you select a customer, the Collector Review - Customer Update Screen appears via which you can process collections information for the customer.

NOTE: The title of this screen may vary based on your selection at the Function field.

In the grid, customers in red or yellow indicate an alert condition. For details, see the documentation for the Function field.

Collector Collector

Enter the code of the collector you want to review. If you click on the Search button, a list of collectors appears from which you can choose.

Function Function

Specify the list of assigned customer accounts you want to display in the grid. You have the following options:

Contact - displays customers on the collector’s list with next contact dates and sorts them by ascending next contact date and time. The screen title displays as “Collector Contact List Review”. Customers whose call back date/time has passed display in red and those due within the next hour display in yellow.

Promise To Pay - displays all customers on the collector’s list with promise-to-pay (PTP) dates, sorted by ascending PTP date and last name. The screen title displays as “Collector Promise to Pay List Review”. Customers whose PTP date has passed without payment display in red.

Assignment - displays the collector's assignment list (that is, a list of customers assigned to the collector), sorted in ascending order by last collections activity date, then by last name. The screen title displays as "Collector List Review".

Customer – displays the Collector Review - Customer Update screen, where you can view selected customers currently in collections, whether or not they belong to the collector’s Assignment List.
