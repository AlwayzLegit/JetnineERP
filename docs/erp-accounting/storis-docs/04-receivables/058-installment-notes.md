Access

Installment Receivables > Manage and Adjust Installment Contracts > Review Contract Details button > Search button by Notes field

Use this routine to enter, edit, or read notes pertaining to the selected installment account. When you access this screen, a text entry window displays. Previously entered notes, if any, display. You can edit these notes, and/or enter new text.
