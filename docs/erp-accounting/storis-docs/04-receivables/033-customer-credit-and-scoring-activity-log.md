Access

Customer Credit and Scoring Information, Actions button, select Credit and Scoring Audit

Use this routine to view and report comments generated automatically when changes were made via the Customer Credit and Scoring Information screen. You can also manually enter comments using this routine.

Customer Code Customer Code

The customer code and name display from the previous screen.

Date Code Date Code

The CUS (Custom Dates) option is already selected and cannot be changed. You can use the next two date fields to enter the starting and ending dates.

Starting Date Starting Date

To view/print comments entered on or after a specific date, click the calendar icon and select a starting date. If you leave this field blank, you can view/report using the earliest available date.

Ending Date Ending Date

To view/print comments entered on or before a specific date, click the calendar icon and select an ending date. If you leave this field blank, you can view/report using the latest available date.

Update Comments Update Comments

To manually enter comments for this customer, check the box at this field. The text entry screen appears, where you can type a text comment.

Comments Comments

System-generated and manually entered credit comments for this customer are displayed. For each comment, the date and time entered, initials, and comment text appears.

Send Output to Send Output to

The output destination of the report data appears. To select a different output destination, click on the Actions button and select Output Settings from the menu that appears.

Export Path Export Path

Because the output options for this routine are limited to Screen and Printer, this field is inactive.

ActionsActions

Output Settings

Print Comments - Send the report to the output destination specified at the Send Output To field.
