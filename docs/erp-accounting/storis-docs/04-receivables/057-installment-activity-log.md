Accounting > Installment > Installment Activity Log

Use this routine to view and/or print the contents of the Installment Activity Log for a selected customer. This log is an internal file you can use to track changes to customer installment records. The file also includes comments you entered manually via the Update Comments option on this screen.

Customer Code Customer Code

When you access this screen from another process, the customer information from the installment contract is displayed and the field is inactive for change. If you access the screen from the menu, you must enter the code of the customer. You can click the Search button to access Search for a Customer.

Date Code Date Code

This field defaults to CUS (Custom) and you cannot edit it. Use the Starting Date and Ending Date fields to restrict the output of the routine to a range of dates.

Starting Date Starting Date

To view comments for a range of dates, enter the starting date here. If you leave the field blank, you select the earliest available date.

Ending Date Ending Date

To view comments for a range of dates, enter the ending date here. If you leave the field blank, you select the latest available date.

Update Comments Update Comments

To enter manual comments for the current customer, check the box. The Text Entry screen appears.

Comments Comments

The selected range of comments and log activity for the current customer appear. The date, time, user initials, and comment text display. Comments are recorded here when a contract is created or rewritten. Comments are also recorded when insurance is added, changed or removed to a contract. When insurance is changed or removed to an existing pending installment contract, the user's initials are saved (rewritten) as the last user to change the insurance on the contract. Comments are also added when you delete a sales order that is linked to a pending contract containing active contracts being rewritten.

Send Output to Send Output to

The output destination of the report data appears. To select a different output destination, click on the Actions button and select Output Settings from the menu that appears.

Export Path Export Path

Because the output options for this routine are limited to Screen and Printer, this field is inactive.

Actions

Output Settings

Print Comments - Send the report to the output destination specified at the Send Output To field.
