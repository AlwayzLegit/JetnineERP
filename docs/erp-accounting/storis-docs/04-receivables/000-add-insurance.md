Access

View All Revolving Plan Activity for a Customer > Add Insurance button

Use this routine to add insurance to active revolving plans for the selected customer. This feature is available if NONE of the customer's plans (including pending) already have insurance and your receivables security setting View All Revolving Activity - Add Insurance is enabled. This action adds insurance to all of the customer's active plans (not pending) at one time.

Total MMP Total MMP

This is a display only field that shows the customer’s current overall MMP.

Insurance Insurance

Click the arrow button and select the insurance plan code from the drop-down list of available plans. The insurance plan you select is added to all of the customer's active revolving plans.

Estimated New MMP $ Estimated New MMP $

This is a display only field that shows the customer’s new overall MMP after the insurance is applied.

NOTE: An Estimated New MMP is only recalculated if the customer has revolving plans that are Fixed Term plans. Otherwise, the new MMP is the same as the Total MMP. The customer’s actual MMP can only be determined when the account cycles.

When you Save out of this screen, a prompt appears asking if you want to print an insurance letter. An additional message displays, indicating that insurance is being added to all of the customer's active revolving plans. If Signature Capture is active for printing insurance letters, the signature and archiving process of the insurance letter takes place after each printing of an insurance letter. Capturing a signature and archiving the insurance letter is only available when printing the insurance letter using the forms designer.
