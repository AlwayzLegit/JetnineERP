This screen appears when you select a payment line from the grid in the Apply Payments and Maintain Vendor Receivables Balances. Use this screen to apply an on account payment to an open vendor receivable.

Select an on-account payment line from the grid. The Vendor Receivables Payment On Account Adjustments window displays. The grid displays open vendor receivable transactions.

Reference Reference

Select the reference line from the grid to which you want to apply the on-account payment.

Amount to Apply Amount to Apply

This field indicates the amount to be applied to the selected vendor receivable. The full amount of the on account payment defaults. This amount can be changed.

Memo Memo

This field displays the reference number of the line item from which the on-account monies were applied, preceded by FR: (From).

For example, if the reference number of the on account payment is 1076, the Memo displays FR:1076. This field can be changed.

Comment Comment

Use this field to enter additional information regarding the application of the on-account payment.

To update the adjustment, click the Add button and then click the OK button at the bottom of the screen to accept the entries and return to the Apply On-Account screen.
