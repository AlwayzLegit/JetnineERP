Access

Indicate Message to Print on Customer Statements, enter a Message Code and then click the Manage Message Assignment extra action button

Use this routine to view and maintain criteria assignments for a specified message. The grid displays the criteria assigned to the indicated message. You can sort the grid display using the Sort by field. Using the check boxes in the grid, you can update criterion assignments for the selected message.

Message Code Message Code

The code of the selected message displays here and cannot be edited on this screen.

Sort by Sort by

Click the radio button next to a criterion to sort the grid display by Plan code, Store, or State name.

Grid Information

The grid displays the criteria assignments you established on the Criteria tab for the selected message. You can remove the assignment of a criterion by removing the check from the box or you can add the criterion by checking the box. If you click the All button, all boxes are checked. If you click the None button, all check boxes are cleared.
