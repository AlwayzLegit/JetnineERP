Access

Installment Receivables > Manage and Adjust Installment Contracts > Review Contract Details button > Search button by Late Fee Forgiven field

Use this screen to view all of the late fees forgiven on the selected contract.

Grid InformationGrid Information

Date - This field displays the date the late fee in that row was forgiven.

$ Amount - This field displays the amount of the late fee.
