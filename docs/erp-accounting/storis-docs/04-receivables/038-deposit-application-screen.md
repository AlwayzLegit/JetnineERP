AccessAccess

Action button at the Apply to field on the Maintain Customer Deposits screen.

If moving a deposit to another order or applying an on-account payment to a deposit on an order, use this screen to select the order to which you want to apply the deposit money. When you double-click on an order in the grid, the Maintain Customer Deposits screen appears and the order number appears in the Apply To field.
