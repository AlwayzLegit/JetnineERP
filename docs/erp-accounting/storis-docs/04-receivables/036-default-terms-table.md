Access

Installment Receivables Payment Plan Settings > Default Terms Table field > Action button

Use this optional routine to create and maintain a table of default term months based on finance amount. This table is used when creating a contract for this plan during Installment Worksheet entry. When you create a table using this screen, the table is built in ascending order of finance amounts.

Finance Amount Finance Amount

Enter the finance amount for which you are entering a corresponding default term. During contract entry, if the amount being financed is equal to or greater than this amount, but less than the next higher amount in the table, the corresponding term in the table is offered as the default.

Term Term

Indicate the number of default term months for the corresponding finance amount. Once you enter/edit the finance amount and term, click the Add button to update the grid.

Grid InformationGrid Information

To add default settings, enter the Finance Amount and corresponding Term months (above) and click the Add button to update the grid.

When you are finished creating the table, click the Save button to update the table.

To edit table settings, double-click a line in the grid.
