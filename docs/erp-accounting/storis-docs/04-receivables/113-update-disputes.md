Access

Adjust Revolving Plans > Update Disputes

Use this routine to place a customer's revolving plan or individual revolving-financed order in dispute. Once a plan or completed order is placed in dispute, assessment of late fees and finance charges is suspended. For disputes that have been resolved, you can use this routine to indicate the resolved date.

Customer Customer

The customer's name and address display.

Plan Plan

The code of the revolving plan displays from the previous screen.

Activated Activated

The date the plan was activated for this customer displays.

Balance $ Balance $

The customer's plan balance displays.

Current Due $ Current Due $

The amount currently due from the customer for this plan displays.

Dispute Order Dispute Order

Click the Arrow button and select whether you want to place All Orders or a specific order/transaction in dispute.

Suspend Interest On Suspend Interest On

Use this setting with the Remove On field during cycle processing to determine how finance charges should be handled while the order/plan is in dispute. You can choose to suspend assessment of finance charges for the Total Balance, Dispute Balance only, or you can choose No Suspension (default setting).

(Dispute) $ (Dispute) $

This field is active only when you select a specific transaction at the Dispute Order field. If you selected All Orders, this field displays the plan balance and is not available for change. If you selected a specific transaction, you can use this field to indicate the amount in dispute. The dispute amount you enter cannot exceed the remaining balance for the transaction.

Reason Reason

Use this field to indicate the reason you are placing the plan/transaction in dispute. Entry of a reason code is mandatory and the code must have a Usage Code of Revolving Disputes. Click the Search button to access the Read-Only Lookup Window from which you can select a code.

Remove On Remove On

You can use this optional field to indicate the date on which you want the dispute to be automatically resolved/removed during month-end processing. To select a date from the calendar, click the Calendar icon.

Resolved On Resolved On

If you want to resolve/remove a dispute immediately, rather than waiting for month-end processing, enter the date upon which you want the dispute resolved. To select a date from the calendar, click the Calendar icon.
