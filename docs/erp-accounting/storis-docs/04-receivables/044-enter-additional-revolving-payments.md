(Enter Additional Installment Payments)

Access

Enter a Customer Payment, Actions menu, Enter Additional Installment Payments

Use this window to enter an additional Installment Receivables payment. This option is available only for customers with at least one active installment contract and no installment payments currently due.

Customer Customer

The customer code displays from the previous screen.

Plan Plan

Click the Arrow button and select the installment contract number for which you are posting an additional payment.

$ $

Enter the payment amount for this additional installment payment.

Click Save to add this payment to the grid on the main screen of Enter a Customer Payment. A reference number with the prefix "AP" is automatically assigned to the transaction.
