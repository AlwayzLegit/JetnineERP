Access

via the Audit Request Activity button in Credit Request Review.

Use this screen to view, print, or update credit review comments for a specific customer and credit request item. The system creates a credit review comments record to hold auto-generated comments in any of the following situations:

application entered

application changed

application reviewed

credit report reviewed

credit report printed

Customer Code Customer Code

The customer code defaults.

Credit Request Credit Request

The credit request number defaults.

Update Comments Update Comments

To update comments, check the box. The Text Entry Screen appears. Otherwise, leave the field blank.

Comments Comments

Any existing comments display.

Send Output to Send Output to

The output destination displays. To change the output destination, click on the Actions button and select Output Settings.

Export Path Export Path

This field is inactive in this routine.

Print Comments - prints the contents of the Comments box based on your output selection on the Output Comments screen.
