Access

Accounting > Revolving Receivables > Metro 2 Features > Download Metro 2 Customer Credit History

Use this routine to export a customer credit history file to a PC or NFS (Network File System) export path.

Import File

Name Name

Enter the name of the file you want to import. If you click on the Search button, a list of credit reporting files appears from which you can choose.

Destination Destination

Enter the destination name of the file you want to import, using up to 20 characters. The name in the Import File Name field defaults, but you can enter a new name. The system assumes a .TXT extension for the file name.

Output To Output To

The output destination displays. If you specified a path at the NFS Export File field on the Receivables tab in the Accounts Receivable Control Settings, "NFS Export Path" displays here. Otherwise, "ASCII Export" displays. You cannot edit this field.

Export Path Export Path

The export path displays. If you specified a path at the NFS Export File field on the Receivables tab in the Accounts Receivable Control Settings, that path displays here. Otherwise, the default export path displays. You cannot edit this field.
