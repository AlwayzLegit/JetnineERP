Use this routine to enter name and address information for the co-applicant on the current credit application. This screen appears during the Credit Application Entry process when you click on the Co-Applicant button at the bottom of the screen. You can also access it via the Actions button on the bottom of the Co-Applicant screens in Credit Application Entry.

Last Name Last Name

Enter the co-applicant's last name. You can enter up to 25 alphanumeric characters.

First Name First Name

Enter the co-applicant's first name. You can enter up to 25 alphanumeric characters.

Middle Name Middle Name

Enter the co-applicant's middle name. You can enter up to 25 alphanumeric characters. This field is active only if a check appears in the Prompt for Middle Name Entry field on the Customer tab in the Point of Sale Control Settings.

Prefix Prefix

Enter a prefix for the co-applicant. You can enter up to five alphanumeric characters. This field is active only if a check appears in the Prompt for Name Prefix field on the Customer tab in the Point of Sale Control Settings.

Suffix Suffix

Enter a suffix for the co-applicant. You can enter up to six alphanumeric characters. This field is active only if a check appears in the Prompt for Name Suffix field on the Customer tab in the Point of Sale Control Settings.

Address #1 Address #1

Enter the co-applicant's address. You can enter up to 30 alphanumeric characters.

Address #2 Address #2

Use this field to enter any additional address information for the co-applicant. You can enter up to 30 alphanumeric characters.

Zip Code Zip Code

Enter the co-applicant's zip code. You can enter up to 9 characters. If the zip code you enter exists in the system, the city and state default from the zip code record. If the zip code does not exist, no defaults for city and state appear. Note that you cannot use this routine to enter new zip codes.

City City

Enter the co-applicant's city. You can enter up to 20 alphanumeric characters. The city (if any) associated with the zip code defaults.

State State

Enter the 2-character code for the co-applicant's state. The state (if any) associated with the zip code defaults.
