Access

Enter a Customer Payment, Actions menu, Additional Payment

Use this window to enter an additional Revolving Receivables payment. This option is available only for customers with at least one active revolving plan with a balance and no MMP's currently due.

Customer Customer

The customer displays from the previous screen.

Plan Plan

Click the Arrow button and select the revolving plan for which you are entering the customer's additional revolving payment.

$ $

Enter the payment amount for this additional revolving payment.

Click Save to add this payment to the grid on the main screen of Enter a Customer Payment. A reference number with the prefix "AP" is automatically assigned to the transaction.
