Access

Maintain Order Credits > Payment Type in grid

Use this routine to view the payment type, date, and amount that was applied to the original order. This screen displays both the credit and debit amounts that make up the credit balance. Credits display as a positive number and debits display as a negative number. The Amount column is totalled to display the overall credit amount.

For payments made on account and manual credit memos, the AR memo reference displays in the Payment Type Code column. If multiple references were used, then '...' appears, where you can use the View Payment extra action to display the multiple references.
