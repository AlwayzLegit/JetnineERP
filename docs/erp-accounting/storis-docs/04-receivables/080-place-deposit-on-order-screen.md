This screen appears via the Actions menu in the Enter a Customer Payment routine. Use this screen to apply the money being received as a deposit to an open order.

Customer Code Customer Code

The customer code from the previous screen displays.

Order# Order#

Enter the open order to which you want to apply this deposit. If you click on the Search button you can use the View a Customer's Open Transactions screen to locate the specific open order.

Deposit Deposit

Enter the dollar amount of the deposit you want to apply to the selected open order.
