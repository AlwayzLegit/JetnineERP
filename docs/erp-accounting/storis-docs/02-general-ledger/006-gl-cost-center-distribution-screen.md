AccessAccess

Via the GL List Entry Window, when you create or edit a GL distribution list. You access the List Entry window via the GL Distribution Screen, which you can access via the Enter/Update Individual Vendor Invoice, when saving after entering an expense invoice.

Use this screen to create GL distribution lists. You can then access the list in the future so you don't have to re-enter the cost center numbers. You specify two or more cost centers to which you want to distribute costs, and the distribution percentage for each. The total percentages must equal 100%

Cost Center Cost CenterEnter two or more cost centers to which you want to distribute costs.

Percentage PercentageFor each cost center you enter at the Cost Center field, enter the 2-digit percentage (1-99) of the total amount you want to distribute to each cost center.
