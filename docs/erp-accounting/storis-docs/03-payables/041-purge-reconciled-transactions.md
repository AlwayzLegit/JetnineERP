AccessAccess

Accounting > Payables > Reconcile Bank Transactions > Purge Reconciled Transactions

Use this routine to purge reconciled bank transactions for any bank set up for bank reconciliation. You must have sufficient security clearance via the Change reconciliation beginning balance in Bank Settings field in Create a User/Group Actions - Payables Security.

The program deletes all transactions that were reconciled before the date specified at the Purge all transactions earlier than field. The process also updates the bank's beginning balance and as-of date in the bank record, using the date you specify here as the new "as-of date".

Bank BankEnter the code of the bank for which you want to purge bank reconciliation transactions. If you click on the Arrow, a list of banks set up for reconciliation appears from which you can choose.

Purge all transactions earlier than Purge all transactions earlier thanEnter the cutoff date for which you want to purge bank reconciliation transactions. You can use the Calendar Icon to speed your date selection. Transactions that were reconciled before this date are purged. Additionally, the date you enter here is used as the new "as-of date" when the bank's beginning balance is updated.
