AccessAccess

Enter/Update Individual Vendor Invoice > General Tab > Exchange Rate field > Search button

Use this screen to display the actual exchange rate (as opposed to the estimated exchange rate) from the Country Settings for the selected vendor and currency.

Vendor VendorThe vendor for the selected AP bill appears.

Currency CurrencyThe currency for the selected vendor appears.

Actual Exchange Rate Actual Exchange RateThe actual exchange rate displays from the Country Settings.
