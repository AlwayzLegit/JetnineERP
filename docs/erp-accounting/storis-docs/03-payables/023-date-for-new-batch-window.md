Use this screen to enter a batch payment date. The date cannot be from a closed sales period. This window appears via the Select and Approve Bills for Payment routine if you select a bank for which no pending check run exists.

Batch Payment Date Batch Payment DateEnter the batch payment date. If you click on the Calendar Icon, a calendar appears from which you can select a date.

Batch Payment Method Batch Payment Method

Select the type of batch payment method. Available options depend on the selected bank's settings.

Check - This option is always available. This is the default selection.

Electronic Funds Transfer - Available when EFT File Format is populated in the selected bank.

Virtual Credit Card - Available when Virtual Card File Format is populated in the selected bank.

NOTE: If the selected bank has both EFT File Format and Virtual Card File Format populated, all three options (Check, Electronic Funds Transfer, and Virtual Credit Card) are available for selection.

If the Export Checks check box is checked on the Third Party Processing tab in Bank Settings, the only available payment method is Check.

Batch Payment Code Batch Payment Code

Use this free-text field to enter up to 10 characters for the code of this batch payment. This field is active and mandatory when the bank is set to allow multiple payment batches. This field is validated to not allow duplicate entries.
