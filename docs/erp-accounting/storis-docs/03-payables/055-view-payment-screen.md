AccessAccess

Accounting > Payables > Process Checks > View Payment

Use this routine to view all AP bills for a selected payment. Information on each AP bill associated with the selected payment appears in the header area and also in the grid.

Bank BankEnter the bank from which the payment whose AP bills you want to view was drawn. If you click on the Search button, a list of banks appears from which you can choose.

Method Method

Specify the payment method of the payment you want to view. If you click on the Arrow, a list of payment methods appears from which you can choose. You have the following options:

CK - Check

DC - Debit Card

CA - Cash

CC - Credit Card

OL - On-Line

EFT - Electronic Funds Transfer

VCC - Virtual Credit Card

Reference Number Reference NumberEnter the reference number of the payment whose AP bills you want to view. For example, if you select Check at the Method field, the reference number of the payment could be the check number.

Once you specify a reference, if you choose Check at the Method field, the payments associated with the reference (if any) appear in the grid. For each payment found, the vendor name, remit-to name, payment amount, and the payment date display.

If you select a payment method other than Check, and multiple payments are found, the Payment Selection Screen appears from which you can select the payment you want to void.

Grid InformationGrid Information

The Type column displays a code for AP bill type. If you double-click on a grid item, the View AP Bill screen appears, which you can use to find more information on the selected AP bill in the grid.
