AccessAccess

Accounting > Payables > Process Checks > Void Checks

Use this routine to void individual payments, for example to void payments after completing a check run or electronic funds transfer (EFT). The program "backs out" the payment for selected AP Bills and reverses the GL postings associated with the payment.

Bank Bank

Enter the code of the bank from which the payment you want to void was drawn. If you click on the Arrow, a list of banks appears from which you can choose.

Method Method

Specify the payment method of the payment you want to void. Select from a list of payment methods appears from which you can choose. You have the following options:

CK - Check

CC - Credit Card

OL - On-Line

DC - Debit Card

CA - Cash

EFT - Electronic Funds Transfer

VC - Virtual Credit Card

Reference ReferenceEnter the reference number associated with the payment you want to void. For example, the reference number can be a check number or the last four digits of a card number. You can enter up two 25 alphanumeric characters, including spaces. Information on the payment appears in the grid.

Once you specify a reference, if you choose Check at the Method field, the payments associated with the reference (if any) appear in the grid. For each payment found, the vendor name, remit-to name, payment amount, and the payment date display. To void the payments, click on Save.

If you select a payment method other than Check, and multiple payments are found, the Payment Selection Screen appears from which you can select the payment you want to void. When you return to the Void Payment screen, click on Save to void the selected payment.

NOTE: This program allows you to void a check in a sales overlap period.

Grid InformationGrid Information

The Type column displays a code for AP bill type. If you double-click on a grid item, the View AP Bill screen appears, via which you can find more information on the selected AP bill in the grid.
