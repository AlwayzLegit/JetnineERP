Use this screen to select AP bills you want to add to an existing check run. This screen appears if you click on the Action button at the Select Bill(s) field in the Add Bills to Existing Check Run screen.

The grid displays options based on the current selection criteria specified on the Bill Selection tab in the Select and Approve Bills for Payment routine. You can select any number or combination of bills. The grid contains all entries for the selected bank. If you select a bill that doesn't meet the criteria specified on the Bill Selection tab, a warning message appears but you can proceed if you want to.
