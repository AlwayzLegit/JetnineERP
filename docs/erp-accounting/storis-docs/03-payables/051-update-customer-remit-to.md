AccessAccess

Enter/Update Individual Vendor Invoice > Select RFND vendor > Action button at the Pay field > select Update Remit-to

Use this screen to override the customer's remit-to address temporarily and send this customer refund to an alternate address. Note that any changes you make here do not update the Customer Settings.

The read-only version of this screen is accessed if the Create vendor remit-to addresses during vendor invoice entry setting in Create a User/Group Actions - Payables Security is not checked.
