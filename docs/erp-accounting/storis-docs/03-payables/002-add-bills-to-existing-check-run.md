Use this screen to manually add AP bills. You access this screen via Add Bill option on the Bill Approval tab in the Select and Approve Bills for Payment routine.

Bill Number(s) Bill Number(s)

Enter the number of the AP bill you want to add to the check run specified in the Select and Approve Bills for Payment routine. If you click on the Search button, a list of AP bills appears from which you can choose one or more. If you click on the Action button, the AP Check Approval Bill Selection screen appears from which you can also choose one or more AP bills.

If you specify a single AP bill number, the program qualifies it using the current selection criteria specified on the Bill Selection tab in the Select and Approve Bills for Payment routine. If the bill has changed so that it no longer matches those criteria, a warning message appears but you can proceed.

If you click on the Search button, a multi-select grid displays with options based on the current selection criteria specified on the Bill Selection tab. You can select any number or combination of bills. Note, however, that the system selects the AP bill file using current selection criteria specified on the Bill Selection tab. Therefore, items already contained on the check run may display. If you select bills that already exist on the check run, the program ignores them. If they don't already exist on the check run, the program adds them. Note that the program consolidates bills into existing checks or creates new checks if necessary.

If you click on the Action button, the AP Check Approval Bill Selection screen appears displaying entries for bills not already on the check run.
