AccessAccess

Virtual Card Processing > Search button at Virtual Card Batch Number field

Use this routine to search for a virtual card batch number.

Once a bank is selected in the previous screen (Void Payment Batch page in Virtual Card Processing), the Bank field is automatically populated and inactive. Double-click a grid item to select it. The window closes and returns you to the previous screen with the selected information.

The grid displays the following information:

Batch Number - The identifier of the virtual card batch.

Date - The date of the virtual card batch.

Time / Code - This dynamic column displays the Batch Code for multiple payment batches, and Batch Time for a single batch payment.

Amount - The total amount of the virtual card batch.
