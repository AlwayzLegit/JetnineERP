Access

Accounting > Payables > Enter/Update Individual Vendor Invoice

Accounting > Third Party Accounting > Payables > Enter/Update Individual Vendor Invoice

Tabs: General, Invoice Detail, Check Information

Use this routine to:

edit open or view closed AP bills linked to a purchase order

enter and edit expense bills not linked to a purchase order (STORIS Accounting only)

create an AP credit for a direct ship reimbursement

delete AP bills (for TPA users, delete un-transmitted bills)

convert pending AP bills to open AP bills

NOTE: You cannot edit AP bills that are currently on a pending check run.

If you access this routine via the Enter Multiple Vendor Invoices routine (as opposed to accessing this routine directly from the Accounting menu), many fields on the screen fill with default values generated by responses you made in that routine. Some of the field documentation in this topic assumes no values were entered into a particular field and instructs you on how to enter a response. You can ignore these instructions. The basic functionality of this routine is the same regardless of how you access it.

GL Posting

This routine posts to General Ledger immediately upon filing. Summary GL hits stored in the AP bill header are available for change prior to filing via the GL Postings screen.

Bill

Enter the number of the bill you want to view or edit. If you click on the Search button, a menu of search options appears:

AP Bills

View Vendor Closed Bills

View Vendor Open Bills

If STORIS AP Processing is active, you can create a new expense bill by pressing Enter or clicking the Plus button to automatically assign the next sequential number. The system assigns the next available bill number as defined at the Next Number field in the Payables Control Settings.

TPA#

STORIS Accounting Only: The Third Party Accounting (TPA) reference assigned by the TPA appears.

Status/Mode

The mode-status of the AP bill and the process mode of the routine appear in the upper-right of the screen. You can access this process in the following modes:

Approval - Accessed as Step 3 of the AP Approval Process

Maintenance - Accessed via the Accounting to

- fix invalid items

- delete un-transmitted items

- delete transmitted items

Inquiry - Accessed via the Accounting menu to

- view un-transmitted items

- view transmitted items

Open Amount $

The (open) amount not approved for payment on this AP bill displays here.

NOTE: After you specify a bill number, a paper clip icon appears on the button bar next to the Help button. If this icon is active (that is, bold-faced) on a tab, it indicates a file attachment exists for the selected tab or for an item in the order related to the selected tab (for example, a customer or product image file). If the icon is dimmed, no attachments exist for selected tab.

General
Company

Specify an expense company for this transaction. The following scenarios affect your response to this prompt.

If you are using multi-company processing (specified at the Multi Company Processing field on the Advanced Setting tab in the General System Control Settings), and the AP Prompt for Company field is checked (in the Payables Control Settings file), then you must manually enter the expense company for this AP bill.

If you are using multi-company processing and the AP Prompt for Company field is NOT checked in the Payables Control Settings, the contents of the Company field (next to the AP Prompt for Company field) defaults here.

If you are NOT using multi-company processing, the default expense company appears here.

Date

Enter the AP transaction date (that is, the current date). If editing an existing bill and STORIS AP Processing is active, you can edit the date that appears. Note that the date in this field must be from an open sales period.

Type

Specify the AP bill type. You have the following options:

02 - Expense/Invoice

03 - Freight/Invoice

12 - Expense/Credit

13 - Freight/Credit

If you accessed this screen via Enter Multiple Vendor Invoices, this field defaults and cannot be edited.

Vendor

The vendor to whom payment is due appears.

If entering a new bill and you enter a vendor code that doesn't exist in the system, the Vendor Settings screen appears and you can enter a new vendor on-the-fly (provided you have security clearance via the Able to Create AP Bill Vendor On the Fly in the User settings).

When a vendor is entered for a new vendor invoice, comments, if any, appear if the Display Comments setting in Vendor Settings is checked.

Status

The current or last status of the AP bill appears to the right of the field. To change the status, click on the Arrow to the right of the field and choose from the following list of statuses:

Null - Open

C - Closed

H - Hold

P - Pending

D - Deleted (Closed only)

Hold Code

Enter the hold code (if any) you want to attach to this AP bill. If you click on the Arrow, a list of hold codes appears from which you can choose. This field is active only if you set the Status field to Hold.

Invoice
Invoice/Credit Number

If approving items for payment, enter the invoice number received from the vendor. If approving a vendor credit, enter the reference number.

direct-ship invoice

vendor receivable credit

service warranty credit

adjusted inventory credit

Invoice/Credit Date

Enter or select (from the drop-down calendar) the date of the invoice or credit received from the vendor.

If editing an existing bill, the invoice date appears, but you cannot edit it if payments have been made on the bill.

Terms

The AP Terms Code defaults from the first line item of the purchase order, if available.

If using STORIS AP Processing, you can edit the terms via the Terms field on Check Processing tab.

If using TPA, this field is available only if approving debit items. If you click on the Arrow to the right of the field, a list of terms codes appears from which you can choose.

NOTE: If you access this routine from Enter Multiple Vendor Invoices where you selected multiple purchase orders for the same vendor remit-to but the purchase orders have different terms codes, the program creates the bill using the terms specified for the vendor in the Vendor Settings. If no terms code exists for the vendor record, the program uses the terms set in the Payables Control Settings.

Pay Prior to Receipt

This field is only active for pending bills that have not been partially paid if the Allow Payment of Pending Bills field is checked in the Payables Control Settings and you are using STORIS Accounting. The setting for this field defaults from the purchase order and can be edited.

If this field is checked, it allows for the immediate payment of the bill via Quick Check Active and Alternate Payment Method on the Check Information tab.

Exchange Rate

The exchange rate appears. Use this field to enter a new exchange rate for bills for foreign vendors. If you click on the Search button, the Actual Exchange Rate Lookup appears.

Whenever you change the exchange rate, the system recalculates all domestic amounts and updates the appropriate GL accounts. If using TPA, this field is active only for new bills. If using STORIS AP Processing, this field is active only for unpaid bills.

Access to this field is controlled by the Change Exchange Rate During Vendor Invoice Entry field in the Extended Security settings.

Amount

NOTE: The Freight, Sales Tax, and Miscellaneous fields below can be used to specify one or multiple sales tax, freight, and miscellaneous invoice charge codes and their associated charge amounts.

For existing bills, the Freight, Sales Tax, and Miscellaneous AP header charge code fields are populated from the data in the AP bill. These fields display either a single Invoice Charge or an ellipsis indicating multiple Invoice Charges.

When in Approval Mode or creating an unlinked expense bill, the AP header charge code fields are defaulted from the standard Invoice Charges: FREIGHT in the Freight field, TAX in the Sales Tax field, and MISCELLANEOUS in the Miscellaneous field.

The ability to specify multiple AP header charge codes is not available when Third Party Accounting (TPA) is active.

Freight

For existing bills, the header charge code for freight fills in from the AP bill. If you accessed this screen in approval mode, or are creating an unlinked expense bill, this field defaults to the standard invoice charge code of FREIGHT.

Click the Arrow button to select a different code from the list of invoice charge code. If you click the Action button you access the Disburse Payable Invoice Charges screen, where you can enter and maintain multiple freight invoice charge codes and amounts on the AP bill.

Freight $

If the invoice includes freight charges, enter the freight amount into this field. If you entered multiple codes and amounts via the Disburse Payable Invoice Charges screen, this field displays the total of those charges.

NOTE: If a value exists for the selected vendor in the Free Freight Minimum field in the Vendor Settings and the total of the current invoice is greater than that value, the order qualifies for free freight. If you then enter an amount here, a warning message appears but you can continue.

Sales Tax

For existing bills, the header charge code for sales tax fills in from the AP bill. If you accessed this screen in approval mode, or are creating an unlinked expense bill, this field defaults to the standard invoice charge code of TAX.

Click the Arrow button to select a different code from the list of invoice charge code. If you click the Action button you access the Disburse Payable Invoice Charges screen, where you can enter and maintain multiple tax invoice charge codes and amounts on the AP bill.

Sales Tax $

If the invoice includes sales tax, enter the tax amount into this field. If you entered multiple codes and amounts via the Disburse Payable Invoice Charges screen, this field displays the total of those charges.

Miscellaneous

For existing bills, the header charge code for miscellaneous fills in from the AP bill. If you accessed this screen in approval mode, or are creating an unlinked expense bill, this field defaults to the standard invoice charge code of MISCELLANEOUS.

Click the Arrow button to select a different code from the list of invoice charge codes. If you click the Action button you access the Disburse Payable Invoice Charges screen, where you can enter and maintain multiple miscellaneous invoice charge codes and amounts on the AP bill.

Miscellaneous $

Use this field to enter any miscellaneous charges from this invoice. You can enter a negative amount. If you entered multiple codes and amounts via the Disburse Payable Invoice Charges screen, this field displays the total of those charges.

Total Invoice/Credit Detail $

The label for this field displays Total Invoice Detail for invoices, or Total Credit Detail for vendor credits. The approved total from the Invoice Detail tab displays here.

Invoice/Credit Total $

The label for this prompt displays INVOICE TOTAL for invoices, or CREDIT TOTAL for vendor credits. Enter the total invoice/credit amount, including freight, tax, and miscellaneous.

NOTE: When creating freight bills, if the Freight in Terms Amount field is not enabled in the Payables Control Settings, the system defaults the pay date instead of the terms date.

The three standard invoice charge codes (Freight, Sales Tax, and Miscellaneous) can be set to inactive by checking the box at the Default Invoice Charges to Inactive in the Payables Control Settings. If this setting is enabled, you can enable these fields on an as-needed basis by clicking the Actions button and selecting Activate Invoice Charges.

Invoice Detail

Use this tab to edit open AP bills linked to a purchase order and enter and edit expense bills not linked to a purchase order (STORIS Accounting only).

Proof Amount

The difference between the total invoice amount on the General tab and the approved total on the this tab appears. To exit this routine, the proof amount must be 0.00 (that is, the total invoice amount must equal the approved total).

Available for Approval
Vendor, PO or RA Number, Receipt Date, Quantity, Unit Cost $, Extension $

If editing an existing bill, these fields of information display following selection of a product from the grid.

Approved Total

The total cost of the invoice (that is, the sum of the approved quantity of all items in the grid multiplied by the sum of the unit costs of all items in the grid) appears here.

Approved for Payment
Reference/Product

If editing an existing bill, you can enter the Product code or double-click a line in the grid.

If editing a linked bill with a bill type number 01 - Merchandise/Invoice on the General tab, you can click the Action button to access the AP Select Available Screen (STORIS AP only) appears, from which you can select items.

If creating an expense bill not linked to a purchase order, enter a free-text Reference for the item you want to approve for AP billing. Do not enter a product code.

If creating an expense bill to an order with a linked protection plan, the Protection Plan Code is displayed.

Vendor Model

If editing an existing bill, the vendor model number from the selected product record displays.

For expense bills related to protection plans are being edited, the 3rd Party Plan Provider code is displayed.

For expense bills not linked to a purchase order, enter a free-text vendor model (if any) for the item you want to approve for AP billing.

Description

If editing an existing bill, the product description from the selected product record displays.

For expense bills not linked to a purchase order, enter a free-text description for the item you want to approve for AP billing.

Quantity

Use this field to indicate the quantity of the product you are approving for AP billing.

If a supply order is received and the "RECEIVING – Supply Purchase Orders must be Received setting" is enabled in Purchasing Control Settings, the AP bill process defaults to the quantity received.

If you did not specify a Trip ID, this field defaults to the entire available quantity. If you specified a Trip ID, this field defaults to the Trip's shipped quantity, rather than the available quantity.

Unit Cost

The receiving unit cost displays here. You can edit the amount.

If the bill is in a pending status, you need to Convert Pending Bills. When the bill status is active you can edit the unit cost.

NOTE: If the receipt unit cost differs from the invoice unit cost, the system creates a cost exception.

To give selected users the option to automatically update the Replacement Cost field in the Advanced Product Settings whenever they edit this field, use the Change product replacement cost during vendor invoice entry field in the Extended Security settings.

Extension

The extension amount appears (that is, quantity times unit cost).

Taxable

Check this box to indicate that the reference/merchandise added is taxable. When selected, tax for the merchandise is calculated based on the rate in Sales Tax Settings for national tax.

When accessing this process from Enter Multiple Vendor Invoices, as AP bills are created the imbedded tax is added to the AP bill item record only if the Taxable field is checked in the purchase order.

NOTE: This field is only active if the Imbedded National Tax setting in Point of Sale Control Settings is set. By default it is unchecked.

After you finish entering payable or credit information (product, quantity, unit cost) for a grid item, select Add. The system returns to the Reference/Product field, where you can approve additional products (if any) for AP billing. When you finish entering payable or credit information, select Save to create the bill. If using TPA, the program adds the approvals to a batch that you can transmit to your third-party accounting package.

NOTE: If using TPA, when deleting untransmitted approvals, the only options available are Delete (to delete selected invoices) and Exit (to exit the program without deleting the untransmitted invoices selected).

Pay

Enter the code of the vendor remit-to address to use for this AP bill. The remit-to address of the current vendor displays to the right of the field. The vendor remit-to name lists first followed by the additional name (if any). Note that the additional name does not display for customer refund bills.

Click the Arrow to select from a list of vendor remit-to addresses. For each address, the vendor remit-to name lists first followed by the additional name (if any). If you click on the Action button, a menu appears with the following options:

View Remit-to

Update Remit-to

You can also create and/or maintain vendor remit-to records on-the-fly (except for refund AP bills) provided you have security clearance via the Extended Security (Payables) settings.

NOTE: If you use the RFND vendor (that is, if issuing a customer refund), these fields access the Update Customer Remit-To screen, via which you can change or view the customer remit-to address (instead of the vendor remit-to address). Depending on your settings, you may access a read-only version of the Update Customer Remit-To screen.

When a new AP bill is created, the vendor remit-to is populated automatically when the Default Vendor Remit To setting in Payables Control Settings is enabled. When that setting is not enabled, this Pay field defaults to "None Selected".

Comment

Use this field to specify a default check print comment.

Payment
Bank

Enter the check print bank. The default bank from the Vendor Remit-To Settings displays, if any. If not, the default bank from the Vendor Settings displays, if any. If a bank is still not found and multi-company processing is active, the system defaults the bank from the Company Settings. If a default bank is still not found, the system references the bank from the Payables Control Settings.

You can override the default. If you click on the Search button, a list of available banks appears. If using multi-company processing, the program restricts the list to banks associated with the company selected at the Company field on the General tab. NOTE: If you select Cash as an Alternate Payment Method, this field is inactive.

Pay Date

The pay date displays. This field defaults to the Terms Date, if one exists. If not, the field defaults to the Due Date.

To edit this field, you must have access via the Change transaction entry date for new payable bills field in Create a User/Group Actions - Payables Security settings. Note that the date in this field must be from an open sales period.

Amount

This is the terms amount.

If the Advanced- Include Freight in Terms Amount setting in Payables Control Settings is enabled, the freight charge is included.

You can edit this field. Note that the system recalculates this amount each time you edit the Total Invoice Amount field on the General tab.

NOTE:The terms amount does not include the sales tax or other miscellaneous charges.

Quick Check Active

To activate Quick Check Processing, check the box. Security restrictions apply. If a check does not appear at the Print accounts payable checks field in Create a User/Group Actions - Payables Security settings for the log-on user, a qualified user must enter their user ID and password to override the restriction.

When entering or maintaining existing bills, this setting is active for pending bills if the Pay Prior to Receipt setting is checked in the purchase order.

Separate Check

To pay this AP bill on a separate check, check the box at this field. To combine this bill with other bills for the selected vendor, leave the box blank. This field defaults the setting at the Separate Check per Bill field in the Vendor Settings for the selected vendor, but you can override the default.

NOTE: For debit AP bills, this field defaults to unchecked and you cannot edit it.

Terms

The AP Terms Code defaults from the first line item of the purchase order, if available. You can edit this field. If you click on the Arrow to the right of the field, you can choose from the list of terms codes that appears.

NOTE: This field also appears on the General tab, but you cannot edit the field on that tab.

If you access this routine from Enter Multiple Vendor Invoices where you selected multiple purchase orders for the same vendor remit-to but the purchase orders have different terms codes, the program creates the bill using the terms specified for the vendor in the Vendor Settings. If no terms code exists for the vendor record, the program uses the terms set in the Payables Control Settings.

Alternate Payment Method

Use these fields to select a manual payment method. To access these fields:

A check must appear at the Select alternate payment methods during vendor invoice entry field in Create a User/Group Actions - Payables Security settings for the log-on user.

Method

Select the method of manual payment. You have the following options:

Manual Check - Credits the Bank Payables Cash GL account. (Invoice documents only)

Debit Card – Is treated the same as a manual check for GL purposes. (Credit & Invoice documents)

Cash – Credits the Paid with Cash GL account. (Invoice documents only)

Credit Card - Credits the Paid with Credit Card GL account. (Credit & Invoice documents)

On Line – No GL hit required until the payment date. At that time, it is treated the same as a manual check for GL purposes (Credit & Invoice documents)

NOTE: Only the Manual Check and Cash options are available for payment on refund bills.

Once you make a selection at the Method field, the following fields activate:

Reference

Enter a payment reference, up to 25 characters of alphanumeric text. This is a required field. The following are examples:

manual check number (must be numeric)

debit card number (perhaps last 4 digits)

cash text specified by user

credit card number (perhaps last 4 digits)

on-line bank reference

Date

Enter the payment date. This is a required field. For on-line payments, enter the delivery date. You can enter a past date as long as it is not in a closed sales period.

Amount

Enter the payment amount.

NOTE: When filing AP bills other than pending AP bills, the GL Postings screen appears.

The alternate payment method is not available for vendor credit bills.

Credit card and cash payments cannot be included in the Bank Reconciliation.
