AccessAccess

This process, called up from the Select and Approve Bills for Payment process when "Select Bills" is clicked, oversees whether the fields necessary for the EFT file format of the Remit To bank are filled in.

The required fields are:

Financial Institution
Transit Number
Account Number

If a required field is not filled in for the Remit To bank, the following message appears: "The settings required for Electronic Funds Transfer are not populated in the following Vendor Remit To(s): XXXX. All bills for these Vendor Remit To(s) have been removed from this batch."
