AccessAccess

Reconcile Checks > click Save button to access Accounts Payable Check Reconciliation Screen

Use this routine to view a list of reconciled and non-reconciled checks and select checks to be reconciled. This screen appears via the Reconcile Checks routine after you click on Save.

The grid lists all checks in the check range with a status of Printed, Reconciled, or Voided, and places a check next to all checks that have already been reconciled or voided. Printed checks are unchecked. Check the box next to any checks you want to reconcile, or remove the check from any you don't want to reconcile. Use the All or None buttons to select all or none, respectively.

NOTE: You can un-check reconciled and voided checks, although un-checking voided checks has no affect on updates.

When you click on Save, a warning message may appear indicating that voided checks have been unchecked. Then, the program assigns a status of Reconciled to all selected checks and a status of Printed to all unselected checks.
