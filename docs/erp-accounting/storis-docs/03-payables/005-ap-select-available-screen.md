This screen appears (for type 1 bills only) via the Action button at the Product field in the Enter/Update Individual Vendor Invoice routine. Use this screen to select items for payment.

NOTE: This screen is not available if using TPA. Otherwise, this screen displays automatically whenever you specify a model number for which multiple items exist.

You can use this process to select refund bills for deletion.

Grid InformationGrid Information

The screen displays all items on open purchase orders for the selected bill type and vendor (except items already selected for payment in the Enter/Update Individual Vendor Invoice routine).

Model - displays either product or vendor model number, depending on your selection at the Display field in the Payables Control Settings.

PO or Reference - The PO or Reference column displays the purchase order number or the reference number for unlinked items.

Available - quantity available to be approved for payment

Date - receipt date

To select an item for payment, double-click on it. When you return to the Enter/Update Individual Vendor Invoice routine, you can adjust the quantity and cost of any item.
