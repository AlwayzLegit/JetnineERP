AccessAccess

Search button at the EFT Batch Number field in the Void EFT Batch routine.

Use this screen to select an electronic funds transfer batch.

NOTE: If accessing from the Void EFT Batch routine, the bank defaults from that routine and only batches eligible for voiding display in the grid. Reconciled batches are not eligible for voiding.

Bank Bank

Enter the code of the bank containing the batch you want to select. If you click on the Arrow, a list of banks appears from which you can choose.

NOTE: If accessing from the Void EFT Batch routine, the selected bank defaults here and you cannot edit it.

Grid InformationGrid Information

The grid displays the following information for each batch:

Batch number

Batch Date

Batch Time / Batch Code - This dynamic column displays the Batch Code for multiple payment batches, and Batch Time for a single batch payment.

Batch Amount - total amount of the EFT batch
