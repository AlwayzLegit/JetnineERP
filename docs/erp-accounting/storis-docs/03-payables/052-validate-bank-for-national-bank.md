AccessAccess

This process is called up from the Select and Approve Bills for Payment process. It oversees whether the fields necessary for the National Bank EFT file format are specified in the Bank record in the Select and Approve Bills for Payment process.

The following fields are required

Financial Institution

Transit Number

Account Number

Payer Number

Destination Data Center

Originator Short Name

Originator Long Name

Next EFT Payment Number

EFT File Format

If a required field is not filled infor the Bank, the user receives the message "Required field 'XXX' is null in Bank X" for each required field that is not filled in.
