AccessAccess

Double-click on a reconciled grid item on the Reconciliation tab in the Reconcile Bank Transactions Manually routine. The item must be for an auto-reconciled bank.

Use this screen to display detailed information on reconciled batches. Reconciled batches display with an asterisk (*) in the Clr column on the Reconciliation tab in the Reconcile Bank Transactions Manually routine. They include the bank reconciliation record from the STORIS database and the associated record or records from the bank's spreadsheet.
