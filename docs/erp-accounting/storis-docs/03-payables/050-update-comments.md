View AP Bill > Actions button on General tab > AP Bill Comments

View a Purchase Order > Actions button on Logistics tab > Display Comments

Manage Customer Applications > check the Select box for a line and click More Details button

Enter a Shopping Cart > Actions > Audit Comment Log

View Shopping Cart > Actions > Audit Comment Log

Use this screen to view and update comments for the current routine. The header displays read-only information based on the routine from which this screen is accessed. Click the Exit button to return to the previous routine.

Vendor Code, Purchase Order/AP BillVendor Code, Purchase Order/AP Bill

If accessing this screen in payables, the vendor code and purchase order or AP Bill number are displayed.

Customer Code, Credit ApplicationCustomer Code, Credit Application

If you access this screen from the Manage Customer Applications screen, the Customer Code and Credit Application number display. You can use this screen to view credit application comments, but you cannot update comments using this process.

Shopping CartShopping Cart

This field appears if you access the screen from View Shopping Cart or Enter a Shopping Cart. The ID of the shopping cart displays in this field and cannot be changed here.

Starting DateStarting Date

Use this field to enter a starting date of the date range for which you wish to view comments. You may also use the Calendar Icon to select a starting date. If no date is present in this field, the earliest available date is used.

Ending DateEnding Date

Use this field to enter an ending date of the date range for which you wish to view comments. You may also use the Calendar Icon to select an ending date. If no date is present in this field, the latest available date is used.

Update CommentsUpdate Comments

Click this button to add a comment via the Text Entry Screen that opens. After clicking Save, the text box closes and the comment is added to the Update Comments grid as the most recent (first) line.

This button is available also in the read-only version of the screen.

ActionsActions

Output Settings

Print Comments - Select this option to print the comments in format set in Output Settings.

Grid InformationGrid Information

Comments and their related information display in this grid. This grid contains the following columns:

Date - The date the comment was entered in MM/DD/YYYY format.

Time - The time the comment was entered.

User - The initials of the user who entered the comments.

Origin - The method in which the comments were entered, for example, automatic or manual.

Comment - The comment that was automatically generated or manually entered.

To access the Text Display Read-Only screen, select a comment line from the grid.
