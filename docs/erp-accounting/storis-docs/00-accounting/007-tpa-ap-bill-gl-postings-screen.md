AccessAccess

Select either the Bill Payments or Bill Credits option at the Posting Type field in the Correct Transmission Errors routine.

Use this screen to fix GL postings in an AP Bill. You can only fix postings to the default account. Once you specify a bill, information on the bill appears in the header area of the screen.

Bill Bill

Enter the bill for which you want to fix GL postings. If you click on the Search button, a menu appears with the following options you can use to locate a bill:

AP Bill - AP Bill Lookup screen

Bad TPA Batch Lookup

Model Model Double-click on the GL posting in the grid whose account you want to update. Once you select an item, information on the item appears in the grid.

Account AccountEnter the number of the account you want to use replace the default account. If you click on the Action button, the GL Account Entry Screen appears, which you can use to select an account.
