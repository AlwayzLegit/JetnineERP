AccessAccess

Accounting > Third Party Accounting > General Ledger > General Ledger Settings > Account Settings

Use this routine to create and update general ledger accounts for use with STORIS' TPA Interface. This routine is active only if the Third Party Accounting Interface is active on your system.

Account Number Account Number

Enter the number of the account you want to create or edit. If you click on the Search button, a menu appears with the following options you can use to select an account:

GL Account

GL Account Description Lookup

Description Description

Enter or edit a description of the selected account number, using up to 30 alphanumeric characters.
