# D1 — User ID convention

**Status:** proposed

**Decision to make:** Choose the company-wide User ID naming scheme.

**Recommended default (starting position, not an answer):** Confirm the true length limit first, then a deterministic scheme (e.g. first initial + surname, truncated, collision suffix).

**Why it matters:** Effectively permanent; appears in every audit record. The most painful decision to reverse.

**Must be verified first:** The real User ID length limit — the source contradicts itself (five vs four characters; six for RF / Store Barcode users). Run open question 1 in Learn before deciding.
