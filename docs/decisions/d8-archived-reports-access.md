# D8 — Access Archived Reports

**Status:** proposed

**Decision to make:** Decide which roles may see other users' archived report output.

**Recommended default (starting position, not an answer):** `User's Archived Reports` (the delivered default) except named supervisor roles.

**Why it matters:** Defaults to the restrictive option already; widening is deliberate per role.

**Must be verified first:** Which supervisor roles genuinely need colleagues' output.
