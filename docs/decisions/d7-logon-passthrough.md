# D7 — Allow Logon Passthrough

**Status:** proposed

**Decision to make:** Decide who, if anyone, gets `Allow Logon Passthrough`.

**Recommended default (starting position, not an answer):** Off for anyone working across locations or sharing a register.

**Why it matters:** It suppresses the entire User Log In Screen — no location, drawer, or terminal selection at login; everything falls back to the user record.

**Must be verified first:** Which roles, if any, are strictly single-location single-register and would benefit.
