# 11 — Reports & Inquiries Registry

Every report or inquiry named in this pack. Build reports on the **ledger** (`LEDGER-001`) and the
availability resolver (`STK-050`), not on ad-hoc queries — that is what keeps them agreeing with each other.

Common requirements for all of them: honor `SEC-COST-VIEW` (cost columns omitted, not blanked, in exports);
honor `CFG-INV-VENDORMODEL` for the product label via one shared helper; export to CSV/XLSX and PDF;
support saved parameter sets; run asynchronously with a results inbox when large.

## Reporting store

`ITEM-046` requires a flattened `product_pricing` table in the reporting store with an extensible numeric
tier code identifying each price's origin. Build the reporting layer so pricing questions are answered from
that table rather than by re-running the resolver, and so new tiers can be added without schema migration.
